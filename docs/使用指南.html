v1.0.20macOS · Windows在 Claude Code 里使用

你负责说话和拍板，
剪辑交给 aaaai-editor。

它是一整套口播剪辑流程：剪停顿、上字幕、排卡片、配乐与音效、响度、封面、逐帧验收。你不用学剪辑软件，也不用记指令——在 Claude Code 里输入 /aaaai-editor，用平常说话的方式告诉它你要什么。

你在 Claude Code 里输入
/aaaai-editor 帮我剪 ~/Movies/raw/0921.mp4，做成 60 秒竖版，中英双语字幕，开头用最有力的一句当预告
最简单什么都不想写？输入 /aaaai-editor 帮我剪片 就行——它会请你把影片拖进窗口，再一步一步问你要什么。
第 1 步丢素材、说需求一句话也行，或照「提示词格式范本」填一份。
第 2 步回答几个问题风格、配乐、字幕；它会先给你看对照图。
第 3 步看预览、说哪里要改满意了才出正式成片和封面。
01 · 功能亮点

它能帮你做什么

重点不是「功能多」，而是每一步都替你把关：剪点等尾音收完、字幕贴到真实人声、卡片不挡脸、响度落在平台标准。

自动粗剪，不切到字

按停顿剪掉空白，剪点等尾音收完、段头留在起音前。讲到一半重来、「嗯／呃」会列给你看，你点头才删。

字幕贴到真实人声

逐句对齐说话的那一刻；中文、中英双语、原语言＋中文翻译都行。关键词高亮；人坐得低时字幕自动移到下巴下面，不压脸。

开头 3 秒抓住人

把片中最有力的一句剪一份放到开头当预告。不知道选哪句，它会按数字、反差、问句打分推荐 3 句。

20 多种卡片，会避脸

片头标题、数据跳数、清单、金句、对比、头像牌、章节……落定后轻轻呼吸、关键卡片闪一下。人坐得高时卡片自动让开眼睛。

卡片收合：秀证据整套版式

画面收进卡片、人物头冲出框，上方放证据截图、工作流步骤、行动号召，结尾停在「留言关键词」。适合收益证明、成果展示。

声音一次搞定

降噪（先给你听三档）、配乐遇到人声自动压低、7 种音效（金币、啵、咻……）、成片响度锁定 −14 LUFS（各平台通用标准）。

B-roll 三种来源

用你自己的素材最好；也能找免费素材（Pexels），或用 AI 生成——生成前一定先报价、你同意才花钱，每个项目默认上限 $2。

出片前自己先验收

按卡片时间自动抽帧检查、字幕对时体检、封面 15% 安全区检查。没看过实际画面，它不会说「完成了」。

剪完接着写文案

交给「内容生产线」：按你指定的平台（小红书、抖音、X、IG、B站…）写好文案、配图，打包成发布包，按客户记住品牌语气。发帖要你亲手按。

快，而且安全

只解码用得到的片段，60 秒的片预览约半分钟。原始素材永远不删、不改、不移动；API 密钥存在 Mac 钥匙串，只发给官方网址。

02 · 准备

开始之前

一台电脑Mac 或 Windows 都行（需求见下表）。人像去背：Mac 用系统自带的 Apple Vision，Windows 用 Google MediaPipe，都免费、不联网。
Claude Code桌面版或终端版都行；也支持 ChatGPT Codex。Windows 要先装好 Git（安装器会帮你装）。
装好 aaaai-editorMac：双击「双击安装.command」；Windows：双击「Install-Windows.cmd」；也能装 Claude Code 插件。第一次约下载 3GB。
一支素材手机竖拍最理想：人坐画面中间、上半身完整、声音清楚、背景安静。

电脑需求

MacWindows
系统macOS 13 Ventura 以上Windows 10（22H2）或 Windows 11，64 位
处理器Apple M 系列（M1 以上）。Intel 芯片的 Mac 能装，但转录、人像去背、渲染会慢很多，不建议近 5 年的 Intel／AMD 64 位处理器；有 NVIDIA、Intel 或 AMD 显卡的话，出片可以开硬件加速。ARM 版 Windows 暂不支持
内存最少 8GB，建议 16GB最少 8GB，建议 16GB
硬盘至少留 20GB（工具与语音模型约 3GB，其余给素材和成片；手机 4K 素材一分钟约 0.5GB）
网络安装时要下载约 3GB；之后剪片不用联网（只有 B-roll 素材、AI 生成、内容生产线查资料会用到）
怎么看自己的电脑左上角苹果图标 ›「关于本机」：芯片写 Apple M 开头就可以「设置 › 系统 › 系统信息」：看「系统类型」是 64 位、内存大小
WINDOWSWindows 版刚推出，已照 Mac 版同样的流程写好，但还需要在更多 Windows 电脑上实测；遇到问题请把画面截图给 Claude，它会帮你排查。
TIP装完第一次，可以直接跟 Claude 说「帮我检查 aaaai-editor 装好没有」，它会跑一次体检，全部 ✅ 就能开工。详细安装步骤、会装哪些东西、哪些要花钱，见套件里的 docs/00-快速安装.md。
不用花钱剪片、字幕、卡片、配乐、音效、响度、封面全部免费。唯一可能花钱的是「AI 生成 B-roll」，而且每次都会先报价问你。
03 · 手把手

第一次剪片，完整走一遍

以一支 2 分钟的手机口播为例。每一步都写了「你要做什么」和「它会做什么」，照着走就不会迷路。

01

准备素材约 1 分钟

你要做
  • 把影片放在任何你找得到的地方（例如「影片」文件夹）。
  • 要用的照片、截图、logo、自己拍的 B-roll，先放在同一个文件夹，等下告诉它位置。
它会做
  • 在「影片 › aaaai-editor」里建一个新项目；原始素材只读取、不移动、不修改。
02

开口说需求30 秒

在 Claude Code 输入 /aaaai-editor，后面接一句话。想讲得更完整，就用下一章的「提示词格式范本」。

/aaaai-editor 帮我剪片

最短就这样。它会先请你把影片拖进窗口，然后一步一步问。多给一点信息，来回就少一点：

/aaaai-editor 帮我剪 ~/Movies/raw/0921.mp4，做成竖版短视频，中英双语字幕
TIP在 Finder 里把影片文件直接拖进 Claude Code 的输入框，路径就会自动出现，不用自己打。
03

回答开工三问1 分钟

它会问
  • 风格：先发一张风格对照图给你看。
  • 配乐：从 7 首原创常备配乐里挑 1–2 首推荐，或用你自己的音乐、或不要配乐。
  • 字幕：中文／中英双语／不要（英文片就是原语言／加中文翻译）。
  • 素材是横拍的，会多问一句：保持横版，还是裁成竖版。
你要做
  • 选一个就好；拿不准就选它标「推荐」的那个。
  • 下次说「照旧」，会沿用上一支的设置。
04

核对字幕3–5 分钟 · 最重要的一步

它会做
  • 把语音转成文字，自动修常见错字，每句贴到真实人声。
  • 拿不准的人名、品牌名、币名，会剪出那一小段请你听。
  • 给你一支约一分钟的「字幕预览」看对时。
你要做
  • 纠正错字（尤其专有名词）。
  • 双语的话，看英文是否自然。
  • 告诉它哪些词要高亮，例如品牌名、关键数字。
TIP字幕越早定稿越省事：后面的卡片时间都是照字幕排的。
05

剪干净、定开头2 分钟

它会做
  • 列出「嗯／呃」和讲到一半重讲的地方（只列不删）。
  • 推荐 3 句适合放开头的话。
你要做
  • 说「全部删」或「删 1、3」。
  • 选一句当开头预告，或说「开头不用预告」。
06

排卡片、看预览5–10 分钟 · 可以来回几次

它会做
  • 先用一句话写下「观众看完要记住什么」，再按内容排卡片（一个意思一张卡）。
  • 出一支半分辨率的预览，自动抽帧检查有没有压脸、撑出卡片。
  • 把预览文件发给你，并在 Finder 里点出来。
你要做
  • 看完直接说哪里要改：「第 20 秒那张卡太久」「清单换成编号行卡」「这里加头像牌」。
  • 满意再往下走。
注意预览版 final_preview.mp4 只用来看版面，画质是一半，不是成品。
07

听声音2 分钟

它会给你听
  • 配乐 A/B：同一段、三种音量的 MP3。
  • 降噪 A/B（有冷气、风扇声时）：原声／标准／加强。默认已开标准档。
  • 音效：只有你要的时候才加，预览时会请你听。
你要做
  • 选一支：「配乐第二个」「降噪用加强」。
08

出成片与封面几分钟（看片长）

它会做
  • 渲染正式成片：响度 −14 LUFS、真峰值不超过 −1 dB。
  • 抽成品的帧再验收一次、字幕对时体检。
  • 做封面（竖版 1080×1920 与 1080×1350；横版片出 1920×1080），检查文字在安全区、不压脸。
  • 成片和封面复制一份到「影片 › aaaai-editor › 成品」。
你要做
  • 给封面一句 6–8 个字的钩子，或让它建议。
  • 用第 12 章的清单看一遍。
09

发布（可选）看平台

它会问你要不要交给「内容生产线」：按你指定的平台写文案、出图、打包。说「要，发小红书和抖音」就行，成片、封面、逐字稿会自动带过去。发布本身要你亲手按——平台不允许 AI 自己发帖。详细用法见第 6 章。

提示词格式范本

不用背指令。复制下面这份，把方括号后面换成你的需求；用不到的行直接删掉，没写的它会问你或用合适的默认。

【片型】口播知识分享，发抖音和小红书          ← 口播／访谈／活动现场；发在哪个平台
【核心】AI 入门最贵的是绕路的时间            ← 观众看完要记住的一句话
【片长】60 秒以内
【风格】你推荐                             ← 或写风格名：ink、neon、paper…
【字幕】中英双语；高亮：品牌名、所有数字
【开头】推荐 3 句让我选                      ← 或：用「……」那句当预告
【剪辑】剪掉停顿、口头禅、讲错重讲的（先列给我看）
【介绍】我叫 MR ONE，AI 工作流 · 一人公司；头像 ~/Pictures/头像/me.jpg   ← 第 5 章
【卡片】说到「三个弯」时做编号清单

【声音】配乐小声一点；有风扇声先给我听降噪；数字出来加金币声
【结尾】停在留言卡：留言「入门」我发链接
【画幅】竖版 9:16
【封面】封面字：AI 入门别绕路
【发布】剪完交给内容生产线：小红书、抖音各一条文案        ← 第 6 章
【其他】专有名词：MR ONE、Claude Code

每一行怎么填

【素材】

影片路径（在 Finder 里把文件拖进 Claude Code 就会出现路径）。多支素材、照片、截图、logo、自己的 B-roll 都写上。

【片型】

口播、访谈、活动现场，以及要发的平台。平台决定画幅、节奏和封面尺寸。

【核心】

观众看完要记住的一句话。卡片、开头、封面都会围绕它，写了成片会更集中。

【风格】

写风格名，或「你推荐」。风格决定卡片与字幕的配色字体（第 8 章）。

【字幕】

中文／中英双语／原语言＋中文／不要；要高亮的词；字幕要不要大一点、高一点。

【开头】

指定哪一句当开头预告，或让它推荐。「开头加片头标题：……」也写这里。

【剪辑】

剪停顿（默认会做）、口头禅与 NG；想保留的段落、想删的段落。

【介绍】

你的名字、身份（一行就好），和头像照片放在哪里。有照片出「头像牌」，没照片出「人名条」。怎么准备照片见第 5 章。

【卡片】

用「讲到……的时候」描述时间点就好，不用精确秒数。常用说法见第 7 章每个组件的「这样说」。

【秀证据】

有收入、后台、订单、评价截图时写。截图要是真的，它不会替你编数据。

【声音】

配乐选哪首、大小声；降噪；要不要音效、要哪几种。

【结尾】

片尾标题、行动号召（留言关键词、关注、私信），要不要停在卡片上到结束。

【发布】

剪完要不要顺便写文案、打包：发哪些平台、各几条。不写，剪完它也会问你。

【其他】

片长上限、必须保留的句子、容易听错的专有名词、账号名（封面右下角）。

三个填好的例子

最简单 · 一句话开工

/aaaai-editor
【素材】~/Movies/raw/ai-3-mistakes.mp4
【片型】口播知识分享，发抖音、视频号
【核心】新手学 AI 最常绕的三个弯
【片长】60 秒以内
【风格】ink
【字幕】中英双语；高亮每个「弯」的关键词
【开头】推荐 3 句让我选
【剪辑】剪停顿、口头禅，讲错重讲的列给我看
【介绍】我叫 MR ONE，AI 工作流 · 一人公司；头像 ~/Pictures/头像/me.jpg
【卡片】开头加片头标题「入门的三个弯」；讲到第一、二、三个弯时各出一张编号行卡；
      最后那句金句做金句卡；说「我是 MR ONE」那句出头像牌
【声音】配乐 focus-quiet；不要音效
【结尾】片尾：关注我，下期讲怎么选工具
【封面】你帮我想 3 个 8 字以内的

为什么这样写：知识类重在「结构清楚」，所以用编号行卡把三个重点钉住；不加音效让内容更沉稳。

【素材】~/Movies/raw/week-income.mp4；截图在 ~/Desktop/proof/（后台.png、订单1.png、订单2.png）
【片型】成果分享，发小红书和 IG Reels
【核心】随手拍 3 分钟，AI 剪完一周进账
【风格】你推荐
【字幕】中文；金额高亮
【开头】用「这一周我什么都没剪」那句当预告
【秀证据】讲到收入的时候用卡片收合、纸面背景：
      第一段放后台截图，说出金额那一刻盖「+$1,593」印章加金币声；
      第二段两张订单截图并排，接着出工作流：随手拍 → AI 自动剪辑 → 每周进账
【声音】配乐 upbeat-energetic 小声；卡片弹出加「啵」

【封面】一周进账，我没剪片

为什么这样写：秀证据的片最怕「空口说」，卡片收合把截图放在人的正上方，印章对准说出数字的那一刻，可信度最高。截图必须是真的。

/aaaai-editor
【素材】~/Movies/summit/stage.mp4（横拍）；嘉宾照片 ~/Movies/summit/guest.jpg
【片型】活动精华，发 YouTube Shorts 和 LinkedIn
【片长】90 秒以内，只留嘉宾讲最精彩的三段
【风格】trust
【字幕】原语言（英文）＋中文翻译
【剪辑】现场有观众回应，降噪用标准档就好，别把观众声音压掉
【卡片】嘉宾第一次出现时加头像牌（姓名、职位）；讲到数字时做数据跳数；
      三段之间用章节断章隔开
【画幅】裁成竖版 9:16，人放中间
【结尾】片尾：完整演讲在主页

为什么这样写：活动片常是横拍，要先说清楚裁成竖版；有观众回应时用标准降噪，加强档会连观众声一起压掉。

一句话懒人版
/aaaai-editor 帮我剪 ~/Movies/raw/0921.mp4，照旧

「照旧」＝沿用你上一支的风格、配乐、字幕设置；其他细节它会在过程中问你。第一次用就把「照旧」换成「做成 60 秒竖版，中文字幕」。

TIP时间点用「讲到……的时候」「最后那句」描述就好，它会用字幕时间表对准；要精确时再写秒数（成片的秒数，不是原始素材的）。
05 · 介绍自己

介绍自己：名字与头像

新观众第一次看到你，最需要知道「你是谁、凭什么听你说」。在你说「大家好，我是……」的那一刻，出一张有名字、身份的卡片——有照片用头像牌，没照片用人名条。

头像牌 avatar 需要照片

长什么样
左下角圆形照片（外圈是风格的强调色）＋名字＋一行身份。
适合
自我介绍；嘉宾第一次出现；讲到某位名人、合作方时（换成对方的照片）。
这样说
说「我是 MR ONE」那句出头像牌，头像 ~/Pictures/头像/me.jpg，身份写 AI 工作流 · 一人公司

人名条 speaker

长什么样
画面下沿：强调色短竖线＋粗体名字＋一行身份，从左边滑入。
适合
没有合适的照片，或画面里已经看得到你的脸。
这样说
自我介绍时加人名条：MR ONE，AI 工作流

头像照片怎么准备

脸清楚、光线亮大头照或半身照都行，正面或微侧，别戴会反光的墨镜。
正方形最好竖拍、横拍也可以——会自动裁成正方形再变圆形，默认保留偏上的部分（脸通常在上面）。
至少 500×500太小的图放大后会糊。手机原图就够。
JPG、PNG、HEIC 都行iPhone 照片（HEIC）不用转档。背景简单一点，圆框里更干净。

照片放在哪里

A

放在一个固定的地方

例如「图片 › 头像 › me.jpg」。之后每支片都用同一张，最省事。

B

告诉它在哪里

在提示词的【介绍】写上路径，或直接把照片拖进 Claude Code 输入框（路径会自动出现）。它会复制一份到项目的 assets 文件夹，你的原图不会被改。

【介绍】我叫 MR ONE，AI 工作流 · 一人公司；头像 ~/Pictures/头像/me.jpg
C

看预览、微调

出预览后看头像牌那一帧，不满意就直接说：

想要这样说
脸在圆框里太低／被切到头像取景往上一点（或「往下一点」）
照片太小头像大一点
换到右边头像牌放右下角
出现太久／太早头像牌晚一秒出来，停三秒就好
想要更醒目头像牌出来时加关注框框住它
身份太长换行身份改成「AI 工作流」
TIP头像牌会对准你说出名字的那一刻出现，停 3～4 秒。一支片通常只介绍一次；系列片可以每集都放，观众更容易记住你。
嘉宾访谈、活动片也一样：「嘉宾第一次出现时加头像牌，照片 ~/Desktop/guest.jpg，名字 Alex Chen，身份 某某公司 创办人」。
06 · 发布

写文案、打包发布：内容生产线

片子剪好，下一步是「发什么文案、配什么图」。套件里的 social-content-pipeline（内容生产线）会按你指定的平台，把成片、封面、文案整理成一份发布就绪包——你打开平台、贴上、按发布就好。

它会做的五件事

01

搜集信息

先从你的逐字稿取事实，再查相关的最新资讯、同类账号在发什么、有没有能借的热点。

02

分析角度

定出这条内容的钩子、目标受众（具体到哪一群人）和语气。

03

按平台写文案

每个平台各写一份能直接发的文案，长度、标签照该平台的规矩；数字和事实都来自你的内容，不编造。

04

配图

有连 Canva 就用它出图（会先问你）；没有也能交付——直接用 aaaai-editor 做的封面，或给你一段具体的配图说明。短视频平台直接用成片。

05

打包、归档

每条内容配好文字＋图片／影片的位置，交给你；同时存一份归档，下次不会重复选题。

两种开始方式

A · 剪完直接接着做（最常用）
  • 成片交付后它会问：「要不要交给内容生产线？」
  • 你回答：「要，发小红书和抖音，各一条」。
  • 成片、封面、逐字稿、风格会自动带过去，不用再给一次。
B · 单独启动（已经有片、或只要文案）
  • 用固定的开头启动：启动内容生产线：、/content-pipeline 或 content pipeline:。
  • 它只认这三种开头；随口说「帮我写条推文」只会得到一条文案，不会走完整流程。
内容生产线范本
启动内容生产线：
【主题】AI 入门最贵的是绕路的时间
【客户】MR ONE（我自己的账号）                ← 每个账号／品牌一份品牌档案
【平台】小红书、抖音、X                        ← 可多选
【数量】每个平台 1 条
【素材】成片 ~/Movies/aaaai-editor/成品/20260921-example-cut.mp4；封面在同一个文件夹
【目标】导流到 9/24 的 AI 入门分享会
【语气】轻松直接，不要营销腔
【必须带】分享会日期；留言「入门」领链接
【不要】「家人们」「绝绝子」；夸大收益
【语言】小红书、抖音用简体中文；X 用英文

从剪片直接接过来时，【素材】会自动带上，其他行照需要写。第一次用某个【客户】，它会先问四个问题建品牌档案（见下方），之后自动沿用。

品牌档案：它会记住每个账号的调性

第一次会问 4 件事主色与视觉风格、语气（专业／轻松／悬念…）、禁忌词与必带声明、输出语言。
存在你自己的电脑文稿 › brand-profiles › 客户名.md，就是一份普通文字档，你也可以自己改。
多个账号分开记帮客户、帮公司、自己的账号各一份，风格不会混在一起。
每次产出自动归档文稿 › content-history › 客户名，下次选题会避开发过的内容。
它不会做① 自动发帖——平台不允许 AI 自己公开发文，最后一步要你亲手按；② 从头生成视频——要剪片请用 aaaai-editor，剪好再交给它打包。
不用 Canva 也行Canva 是可选的：在 Claude 里连接 Canva 后，它会先问你再出图；没连接时，用 aaaai-editor 的封面（竖版 1080×1920、1080×1350，横版 1920×1080），或给你一段写清画面、构图、配色、尺寸的配图说明。

小组件图鉴

左边的小画面是 9:16 竖屏示意：灰色人像是你、白色横线是字幕（约在画面 70% 处）、黄色是强调色。「这样说」可以直接抄进提示词。

08 · 风格

风格一览

风格决定卡片和字幕的配色、字体与质感。开工时它会发一张对照图给你看，说风格名就能换，换风格不用重做别的步骤。前 7 套是通用风格，按内容挑；最后两套是社群风格——可以用，但它们带着 MR ONE、OTG 的品牌印记，一般不建议当你自己频道的主风格。

TIP字幕的关键词颜色会跟着风格的强调色走；想自己指定颜色，说「字幕高亮用 #FF5C7A」。有自己的品牌色也可以做成自定义风格。
09 · 声音

配乐与音效

全部是原创，没有版权问题。配乐遇到人声会自动压低；音效在响度锁定之前混进去，成片响度照样准确。音效默认不加——一分钟 3～6 个就够，多了会吵。

14 · 好习惯

让成片稳定的习惯

先定字幕，再排卡片卡片时间照字幕排；字幕后改，卡片可能要跟着挪。
一个意思一张卡卡片宁少勿多。每 8–15 秒最多一张主卡，30 秒以下的短片：开头＋一张主卡＋结尾。
拍的时候就留好位置人坐画面中间、头顶留一点空间，卡片、文字穿插、卡片接管都会更好看。
专有名词先告诉它品牌名、人名、币名写在【其他】，能少掉大部分错字。
预览不是成品正式成片是 final.mp4，要说「出成片」才会有；预览只看版面。
同一系列照旧说「照旧」沿用上一支设置，各集的风格、音量才会一致。
证据用真的收益、后台、订单截图必须是真实的；它只负责排版，不替你编数字。
花钱的事它会先问AI 生成 B-roll 每次都先报价；看到报价再决定，不同意就不会花。
