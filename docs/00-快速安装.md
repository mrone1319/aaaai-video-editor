# 00 · 快速安装：先选你的电脑

aaaai-editor 影片总监套件在 **Mac** 和 **Windows** 上都能用，两边的功能一样，安装方式不同。请看对应的那一份：

| 你的电脑 | 看这份 | 双击这个安装 |
|---|---|---|
| **Mac**（macOS 13 以上，建议 Apple M 系列芯片） | [`安装指南-Mac.md`](安装指南-Mac.md)（或 `.pdf`） | `双击安装.command` |
| **Windows**（Windows 10 22H2／11，64 位） | [`安装指南-Windows.md`](安装指南-Windows.md)（或 `.pdf`） | `Install-Windows.cmd` |

两份都写了：电脑需求、会安装什么、哪些要花钱、隐私与版权、安装步骤、安装器选项、之后怎么绑密钥与改设置、
在其他 AI 工具里使用（MCP）、5 分钟试剪、更新、卸载和常见问题。

装好之后，打开同一个文件夹里的 **《使用指南》**（`使用指南.html`，双击用浏览器看；或 `使用指南.pdf`）：
手把手的第一次剪片、可以直接复制的提示词格式范本、每个小组件的说明。

| | Mac | Windows |
|---|---|---|
| 安装工具 | Homebrew | winget（Windows 自带） |
| 人像去背 | Apple Vision（需要 Xcode 命令行工具） | Google MediaPipe |
| 密钥存放 | macOS 钥匙串 | Windows 凭据管理器 |
| 项目与成品 | 「影片 › aaaai-editor › 成品」 | 「视频 › aaaai-editor › 成品」 |
| 卸载 | `bash uninstall.sh`（移到废纸篓） | `Uninstall-Windows.cmd`（移到资源回收筒） |
| 状态 | 完整实测 | 刚推出，还需要更多实测 |
