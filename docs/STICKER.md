# 贴纸弹跳（Sticker Pop）

街头口播短视频的「贴纸」包装：卡片都贴在胸口区域（画面 35–70%，**不挡脸**），一张约 1–1.5 秒就换；
弹出带回弹、伴一小簇彩纸；台词逐字打进白框；斜标签压在框角；关键词三种强调；重砸大字；
空心描边先出再填满；斜向黄色色带扫过当转场；手形光标点按的行动号召。

选这个风格：storyboard 顶层 `"style": "sticker"`。会一起换掉：

| 部分 | 样子 |
|---|---|
| 一般卡片（标题、数据、清单…） | 奶油白卡、黑粗描边、右下硬投影（不糊）、粉色强调 |
| 字幕 | **打字框**：每句放进白色贴纸框，框先弹出、字一个个打进去；关键词粉字 |
| 色板 | 粉 `#FF4F9A`、柠檬黄 `#FEDA62`、奶油白 `#FFFCF5`、墨黑 `#0A0A0B`、海军蓝 `#1D1B49`（`brand` 可覆盖 accent／accent2／navy／paper） |
| 字体 | 圆体（macOS「圆体-简」；本机没有就退回苹方） |

贴纸本身是一种卡片：`"type": "sticker"`，用 `kind` 选种类。贴纸**在任何风格下都能用**（色板固定用上面那一套）。

## 种类

```jsonc
{"type": "sticker", "kind": "box", "t": [2.0, 3.4], "text": "我**不想**拍==短视频==", "tag": "只需", "icon": "phone_play"}
```

| kind | 是什么 | 主要栏位 |
|---|---|---|
| `box` | 台词框：字逐个打进去 | `text`、`tag`（框角斜标签）、`tag_fill`、`icon`（框角图标）、`fill`、`typing`（false＝不打字）、`type_speed`、`max_width`、`align` |
| `tag` | 斜标签（小胶囊） | `text`、`fill`（默认粉）、`rot`（默认 -6） |
| `slam` | 重砸大字：从 1.9 倍带模糊砸下、落地压扁回弹 | `text`、`fill`（默认黄） |
| `icon` | 卡通贴纸图标（彩色填色＋黑描边＋硬投影） | `name` |
| `badge` | 圆环计数：数字一步步跳、粉环跟着走满 | `values`（例 `[8, 22, 24]`）、`unit`、`step`（每跳间隔，默认 0.45 秒）、`max`、`label`（斜标签） |
| `checklist` | 打勾清单：一行行弹出、粉色勾一笔笔画上 | `items`（字串或 `{"text", "at"}`）、`gap`（默认 0.42 秒） |
| `cta` | 点击按钮：先出黄色空心描边再填满，手形光标一下下点、涟漪、下面两个往下跳的箭头 | `text`、`fill`、`tap_every`、`arrow` |
| `polaroid` | 拍立得：白框＋黄胶带，从右边滑进来带转 | `file`、`aspect`、`tape`、`from`（left／right） |
| `fan` | 扇形卡片：几张手机截图像一把牌摊开 | `files`、`card_width`、`aspect`、`spread`（度） |
| `flip` | 翻面卡片：正面压扁翻过去、背面展开 | `files`（[正面, 背面]）、`flip_at`（相对秒数） |
| `wipe` | 斜色带转场（一般不直接写，见下方 band） | `fill` |

图标名：`phone_play` `camera_off` `moon` `megaphone` `bolt` `link` `cursor` `pencil` `scissors` `checkbox` `star` `heart` `sparkle` `fire`。

### 通用栏位

| 栏位 | 作用 |
|---|---|
| `xy` | `[中心 x, 中心 y]`（0–1）。默认 `[0.5, 0.42]`：胸口偏上，脸在上面、打字框字幕在下面 |
| `rot` | 倾斜（度，正＝顺时针）；整组一起转 |
| `scale` | 大小倍率 |
| `fill` | `pink`｜`yellow`｜`cream`｜`navy`｜`ink`｜`white`｜`#RRGGBB`；深底自动白字 |
| `anim` | 入场：`pop`（默认，带回弹）｜`slam`｜`ghost`（描边→填满）｜`rise`｜`drop`｜`slide`｜`fade`｜`none` |
| `out` | 出场：`fade`（默认）｜`pop`｜`cut` |
| `burst` | 弹出时的彩纸小爆发（box／slam／icon／badge 默认开，tag 默认关） |
| `sfx` | 默认：弹出「啵」、打勾「喀」、计数「滴答」、点按「喀」、拍立得「咻」；写 `""` 关掉，写别的名字换音效 |

卡片里的时间（清单的 `at`、翻面的 `flip_at`）都是**相对贴纸开始**的秒数。

### 文字标记

| 写法 | 样子 |
|---|---|
| `**不想**` | 粉色字 |
| `==短视频==` | 黄色荧光笔底条（跟着打字一起画出来） |
| `[[AI网红]]` | 粉色实底块、白字 |
| `\n` | 换行（太长也会按真实字宽自动换行） |

## 斜色带转场

```jsonc
"transitions": [{"t": 10.1, "type": "band"}]
```

画面本身是硬切；一大片黄色斜带（前后各一条粉色细带、黑描边）横扫过去，正中间几帧整片盖住剪辑点，扫走后淡淡白闪。
默认 0.40 秒、配「咻」。`fill` 可换颜色。和甩镜一样会吸附到最近的剪辑点（±0.6 秒）。

## 打字框字幕

`"style": "sticker"` 自动用；其他风格也能借用：`"captions": {"style": "sticker"}`。
每句一个框，下一句紧接着出现时直接换框（不淡出）；字幕轨（`work/captions.json`）里写 `==词==` 是黄色底条。
一句最多约 12 个字（框要留边），太长会自动换成两行——口播字幕还是建议在标点处拆短。

## 节奏建议（来自参考片）

- 一张贴纸 1–1.5 秒；几乎每句话都有一个东西在动，但同一时间画面上最多两三样。
- 贴纸放胸口，**不要挡脸**；字幕框在下面，贴纸在上面。
- 重点句用 `slam` 或 `[[实底块]]`，一般句用 `box`；情绪词配图标（`camera_off` 不想露脸、`moon` 今晚、`bolt` 最快）。
- 结尾 `cta`（按钮＋光标）停 2–3 秒；章节之间用 `band` 转场。

## 实作

`aaaai_editor/sticker.py`。矢量部分全部写成 ASS 绘图交给 libass（和富文本卡片同一次 subtitles 滤镜，不多一次编码）：
动画期间逐帧采样成一行 Dialogue（事件边界落在两帧正中间，厘秒取整也不会跳帧），静止期间只写一行；
框的大小按字体档里的真实字宽算（`richtext.advance_table`）。图片贴纸是 ffmpeg 图层（rotate／scale／pad 按时间表达式）。
Studio：「＋ 字卡 → 贴纸」可直接加；矢量贴纸有静态真样子预览，图片贴纸要「渲染这一段」看。
