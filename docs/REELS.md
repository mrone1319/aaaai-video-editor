# 关键词触发、章节目录、整屏特效

三样东西配合起来，就能做「讲到哪个就出现哪个」的清单型 Reels（例如「5 个工具」「18 种特效」）。
都写在 storyboard 顶层，和风格无关（任何风格都能用）。

## 关键词触发（triggers）

讲到某个词，卡片或整屏特效就在那个时间出现，不用手动对时间：

```jsonc
"triggers": [
  {"say": "AI网红", "card": {"type": "sticker", "kind": "slam", "text": "AI网红"}, "dur": 1.4},
  {"say": ["手机框", "手机"], "fx": {"type": "phone"}, "dur": 3.0, "toc": "缩成手机框"},
  {"say": "留言", "card": {"type": "sticker", "kind": "comment", "text": "收藏了！"}, "every": true}
]
```

| 栏位 | 作用 |
|---|---|
| `say` | 要听的词，可给几个写法；不分大小写、忽略空格标点 |
| `card` | 出现的卡片（任何 overlay，不用写 `t`） |
| `fx` | 整屏特效（见下方 postfx，不用写 `t`）；`card`、`fx` 可以一起写 |
| `dur` | 持续秒数（默认 1.5） |
| `lead` | 提前几秒出现（默认 0.1） |
| `every` | `true`＝每次讲到都触发（默认只触发第一次） |
| `after` | 成片秒数：只找这之后讲到的（同一个词讲了好几次时用） |
| `toc` | 同时在章节目录加一项 |

- 时间：跑过 `align` 就用逐字时间（准到一个字）；没有就按字幕轨每句的起止按字数插值（误差一两个字）。被剪掉的段落讲到的词不触发。
- 先查对不对：`aaaai-editor triggers storyboard.json`（不渲染，只列出每个词的成片时间；没听到的会提示）。
- 字幕轨的字要对：听写把词写错了，就找不到（改 `work/captions.json` 或换个 `say` 写法）。

## 章节目录（toc）

画面一侧固定一块深绿目录，列出整支片的段落，讲到哪一段那一行就亮起来，右上角「03/10」。

```jsonc
"toc": {"title": "18 种特效", "footer": "收藏起来慢慢学",
        "items": [{"t": 3.2, "text": "掉落字"}, {"t": 6.0, "text": "巨大字幕"}]}
```

- `items` 的 `t` 是该段开始的成片秒数；用关键词触发的 `"toc": "名称"` 会自动加进来（可以只写 `title`／`footer`）。
- 可选：`side`（`right`／`left`）、`end`（不写＝一直到片尾）、`panel`（底色）、`hl`（亮起那行的底色）、`scale`（默认 1.2）。
- 目录画在所有卡片之上。右侧有目录时，卡片 `xy` 的 x 别超过 0.75。

## 整屏特效（postfx）

只动那一段时间的画面（片长不变），在画面调色之后、卡片和字幕之前——卡片、字幕不跟着缩、不被调色。

```jsonc
"postfx": [{"t": [12.0, 15.0], "type": "phone"},
           {"t": [20.0, 23.0], "type": "split", "labels": ["调色前", "调色后"]},
           {"t": [30.0, 33.0], "type": "swipe", "file": "assets/滑reels录屏.mp4", "start": 2.0, "speed": 1.6},
           {"t": [40.0, 43.0], "type": "film"}]
```

| type | 样子 | 选项 |
|---|---|---|
| `phone` | 整个画面缩进米白手机外框（深绿背景＋黄色时间码＋进度条），段落结尾放大回原状 | `scale`（默认 0.66）、`bg`、`timecode` |
| `split` | 调色前后对比：左边灰平（或黑白）、右边暖色高对比，分割线带把手左右滑动 | `labels`、`before`（`flat`／`bw`） |
| `swipe` | 滑下一支：画面往上滑走，露出手机滑 Reels 的屏幕录像（加速播放），最后带回弹滑回来 | `file`、`start`、`speed`（默认 1.5）、`crop_top`／`crop_bottom`（裁掉状态栏、底部头像列，0–1） |
| `film` | 底片感：暖色、对比、颗粒、暗角、漏光、上下黑边、轻微抖动 | `leak`、`bars`、`shake`（都默认开）、`grain`（倍率） |

- 进出各一声「咻」（底片感不加）；写 `"sfx": ""` 关掉。
- 分段渲染不会在整屏特效中间切开。
- Studio 的播放器不显示整屏特效、目录和关键词触发的卡片：用「渲染这一段」看。

## 来源

点子来自一份网上的「Reels 18 特效包」（它的程序没有授权声明、抠像模型是 GPL-3.0，所以**一行都没有搬**）：

关键词时间用自己的逐字对齐、人物在最上层用现有的人像穿插。只适合「教人剪片」题材的几项（时间轴界面、拖文件框、
图标抖动、滴管取色）没有做。
