# 长片：分段渲染与字幕对时体检

## 逐帧对齐（所有渲染都生效）

每个剪辑点先转到目标帧率，再**锁死帧数**，才拼起来。时间轴（`Timeline`）
也按同样的整帧长度计算，所以卡片、字幕用的时间和画面逐帧对得上。

不这样做，每个剪辑点会各自取整误差 ±1 帧，200 个剪辑点的长片到结尾能漂 1–2 秒。

## 分段渲染

```jsonc
"segment": {"enabled": "auto", "target": 45, "min": 6}
```

| 字段 | 说明 |
|---|---|
| `enabled` | `auto`(默认) / `true` / `false`。auto：成片超过 90 秒、剪辑点超过 120 个或卡片超过 25 张才分段 |
| `target` | 每段目标秒数 |
| `min` | 最短段，避免切出碎段 |

- 切点只落在**卡片与推近之外**（含 0.35 秒淡出余量），动画不会在接缝重来。
- 能切在原有硬切点上就切在那里，不从中间劈开一段素材。
- 每段锁死帧数，各段之和恰好等于整片帧数；各段编码参数相同，**无损拼接**。
- **音轨不分段**：响度按整支片子算，分段会让各段响度不一致。
- `preview` 不分段（半分辨率本来就快）。

## 字幕逐句对齐（align）

`~/.aaaai-editor/bin/aaaai-editor align storyboard.json`：whisper 逐词时间流（不带提示词、繁转简）与字幕轨做全局序列对齐，
每句起点吸附到 ±0.35s 内最近的真实起音、提前 0.05s，句尾贴尾音收完 +0.2s；对不上的用前后插值。
改的是字幕轨的**原片时间**，改剪辑点不用重对。`--dry-run` 只看移动量。

## 剪点（autocut）

默认按能量包络修剪点：段尾延到尾音衰减回底噪 +0.06s，段头放在起音前 0.09s 且要安静；
静音门槛随底噪自适应（底噪统计排除数字静音）。`--no-refine` 回到旧行为。

## 字幕对时体检

```bash
~/.aaaai-editor/bin/aaaai-editor check-sync storyboard.json            # 默认容差 0.4 秒
~/.aaaai-editor/bin/aaaai-editor check-sync storyboard.json --tolerance 0.3
```

两关：

1. **逐句能量检查**（每句都查、不受配乐影响，用原片人声）：出字时有没有人声、有没有比开口早 >0.35s、
   每个剪点有没有切在尾音上（最后 50ms 峰值）／咬到字头（前 30ms 峰值）；剪点之后原片还有人声会列为提示。
2. **重转录**成片音轨（不带提示词），按时间顺序逐句比对，报告偏移与累积漂移；参照点少于 3 个时这一关不下结论。

- 按时间单调对齐：同一句话在片中出现多次，不会全配到第一次出现的位置。
- 成片音轨没变就沿用上次的转录，改完 transcript 再体检只要几秒。
- 退出码：通过 0，有问题 1，可以接进自动流程。

## 长片加速

默认用 x264 slow／crf15（画质最好、最慢）。长片赶时间可以在 storyboard 写 `"output": {"encoder": "hw"}`，
改用 Apple 硬件编码（快数倍、文件稍大、画质略低）；交付前想要最好画质就拿掉这行再渲一次。
