# 图标库（给所有用户用）

放在这里的图标会随套件发布，每个用户、每支片都能直接用名字调用：

```json
{"type": "title", "t": [1, 4], "icon": "binance", "text": "..."}
```

## 规格

- **格式**：PNG，透明背景。（SVG 目前不支持，请先转成 PNG。）
- **尺寸**：正方形，256×256 以上（会自动等比缩放，非正方形会补透明边）。
- **文件名**：英文小写＋连字号，文件名就是图标名，例如 `binance.png` → `"icon": "binance"`。
- **颜色**：
  - **单色剪影**（纯白、纯黑或灰）→ 自动染成当前风格的强调色，和内建图标一致。建议通用图标都做成单色。
  - **彩色 logo**（品牌色）→ 保留原色，不会被染色。
- 名字不要和内建图标重复（`aaaai-editor icons` 看内建清单）；套件库只补内建没有的名字，
  内建图标的外观不会被这里的同名图片换掉。

## 查找顺序

1. 项目自己的 `项目/assets/icons/`、`项目/assets/`（只给这支片用；同名会覆盖内建图标）
2. 内建图标（程序画的，45 个）
3. 套件图标库（这个文件夹）
