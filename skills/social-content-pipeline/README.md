# Social Content Pipeline — 社媒内容生产线

从"我有一个主题"到"文字 + 图片／视频，可以直接发"，一次跑完。五个角色依次执行——情报、分析、文案、视觉、发布准备——每一环都有合格线，上一环的粗糙产出不会流到下一环。

本 skill 随 **aaaai-editor 套件**安装（Claude Code 与 ChatGPT Codex 均可用），**勿单独 clone**。更新套件时本目录会被整体覆盖，所以你的品牌档案与内容归档都存放在 skill 目录之外（见下方）。

---

## 解决什么问题

泛泛的"帮我写条社媒帖"会直接跳到写文案：没有信息支撑、受众不具体，读起来和其他 AI 帖子一样——没错，但记不住。同时为多个品牌／客户做内容时，风格很快就会串味，除非有地方长期记住"这个账号用藏青色和 3D 插画，那个账号极简纯文字"。

本 skill 同时解决这两点：用调研环节为每个说法找依据，用品牌档案让每个客户的风格保持一致，不必每次重新解释。

## 工作方式

说出唤醒词 + 主题，五个角色依次执行：

1. **情报官** —— 搜集最新信息、竞品动态、相关热点；多信源交叉确认，标注时效
2. **分析官** —— 把原始信息变成真正的角度（钩子），定义具体的目标人群与语气
3. **文案官** —— 按你指定的平台分别写可直接发布的文案（X、Instagram、小红书、抖音／视频号／TikTok／YouTube Shorts、B站等），遵守各平台长度与标签规则，标签默认最多 5 个
4. **视觉制作官** —— 按品牌档案出图并处理各平台尺寸；有 Canva 等设计连接器时可用，**没有也能交付**（改用 aaaai-editor 封面、motion-graphic 海报帧，或纯文字 + 配图说明）；已有剪好的成片时直接打包
5. **发布协调官** —— 打包成发布就绪包；**不会**自动发布（见下方能力边界）

每个角色都有合格线：不靠单一信源、不写模板腔（"在……的世界里""让我们一起……"）、不编造数据、CTA 只有一个、图片必须对应文案。不达标就重做，再进下一环。

## 品牌档案与内容归档

同时服务多个品牌、客户或人设时，本 skill 用本地 Markdown 文件把各自的风格分开存放（可以放在 Obsidian 库里，也可以是普通文件夹），不需要额外连接器：

```
<brand_dir>/<客户名>.md                     —— 配色、字体、语气、禁忌、输出语言，每个客户一份
<history_dir>/<客户名>/<日期>-<主题>.md      —— 历次产出归档，避免重复选题
```

`brand_dir` 与 `history_dir` 由 aaaai-editor 设置决定：运行 `~/.aaaai-editor/bin/aaaai-editor config` 查看（保存在 `~/.aaaai-editor/config.json`），默认分别是 `~/Documents/brand-profiles` 与 `~/Documents/content-history`。要换位置，改 aaaai-editor 设置即可，不需要改 SKILL.md。

每次运行：先确认客户名，找到档案就直接用；找不到就一次问四个问题（主色／视觉、语气、禁忌词、输出语言），并先告诉你档案会存到哪里，再写入。只有在即将**覆盖**一份已有且内容冲突的档案时才会打断你确认；新的内容归档自动保存。

## 能力边界 —— 能做什么、不能做什么

| 环节 | 状态 | 说明 |
|---|---|---|
| 调研 | ✅ | 网页搜索最新信息、竞品动态、热点 |
| 分析 | ✅ | 模型自身完成，无外部依赖 |
| 文案 | ✅ | 按你指定的平台分别产出，含长度与标签规则 |
| 图片 | ✅ | 有设计连接器（如 Canva）时经你确认后使用；没有时用 aaaai-editor 封面、motion-graphic 海报帧或纯文字交付 |
| 视频 | ⚠️ 有限 | 不生成视频；已有成片（aaaai-editor 或 motion-graphic 产出）可直接打包 |
| 发布 | ❌ 不自动 | 没有官方发布 API 连接器。可行路径：浏览器自动化（每次由你当场确认）或你自建的第三方自动化（如 Zapier）——本 skill 不代为搭建 |

做不到的事会直接告诉你，不会假装已完成——尤其是视频与发布。

## 使用

唤醒词（必须精确匹配，日常对话不会误触发）：

- `/content-pipeline [主题／目标／参考资料]`
- `content pipeline: [主题／目标／参考资料]`
- `启动内容生产线：[主题／目标／参考资料]`

只写一条推文不需要走完整流程，直接问即可。

**示例：**
> 启动内容生产线：发布我们的新推荐计划，平台：X、小红书，客户：Acme

从 aaaai-editor 剪辑流程交接时，交接信息里可带 `客户：<名>`，本 skill 会直接据此读取档案。

你会得到：
- 发布就绪包：每个平台的最终文案 + 对应尺寸的图片／视频（绝对路径）
- 一份说明：哪些已完成、哪些仍需你处理（发布动作、需要重出的尺寸等）

## 适用场景

**适合：**
- 一个主题需要变成真正可发布的一两条内容
- 同时服务多个品牌／客户，需要风格一致
- 内容需要基于最新的真实信息

**不适合：**
- 一条快速推文或说明文字——直接问即可
- 整月内容排期（本 skill 设计上一次做 1–2 条）
- 需要从头制作视频（请先用 aaaai-editor 或 motion-graphic-video-editor），或需要替你点击"发布"
