# 配方：一张被逐步点亮的 Colony Field 网格

> **作者示例案例（第三方品牌，仅作拆解学习）。** 品牌名、色彩与文案均属原品牌方，
> 不可直接套用到其他项目；可迁移的只是下文的构思结构与实现参数。
> 原片：一支赞助商公告片（24s，模式 A，16:9 + 9:16）。
>
> 案例中三个元素被验证为一组连贯的视觉语言：①底部三色渐变条 ②**点亮之后**节点与
> 网格的分布本身（静态图可直接取稳态那一版）③三道光波依次外扩。它们是同一套三色
> 语义（已认领/扩张中/开放）的三种形态——用其一时应考虑另外两个是否也该在场。

## 一、这是什么

一个**构思级**（§4.7）配方，不是效果配方。贯穿性载体是**品牌自己的网格纹理**，
它在片中以四种形态出现，一个构思吃满全片：

| 形态 | 出现位置 | 画面 |
|---|---|---|
| ① 空网格 | tension（0–2s） | 只有规则线可见，一个种子节点在中心呼吸 |
| ② 被点亮 | burst（2s 起 1.25s） | 冲击波从种子点扩散，扫过之处列在亮、节点炸开 |
| ③ 汇聚成标 | payload（8.7→12s） | 亮节点飞向中心，凝结成赞助商字标，锁定时交接给真 Logo |
| ④ 定格 | resolve（18s→尾） | 网格回到海报的最终密度，全片收在那张静态海报上 |

**为什么成立**：COLONY 的 Colony Field 三色分区（绿→紫→金）在品牌档案里就是
「已认领 → 扩张中 → 开放」的语义，而 B2C 主张是 *Claim the room.*
所以**点亮网格 = 认领这个场**——载体自带叙事，不是装饰。

**换品牌复用时**：这个配方的可迁移部分是"一个有语义的底纹被逐步激活"这个结构。
如果新品牌的底纹没有自带语义，先想清楚"点亮它代表什么"，想不出来就别用这个配方
（否则退化成装饰性粒子，正是 §4.7 要防的零件感）。

## 二、被这个构思排除掉的东西（写下来才有约束力）

3D 挤出、粒子隧道、CRT/扫描线、老虎机数字滚动、第二次冲击。
全部**不用**——即使好看。

## 三、时间轴（24s / 12 小节 @120BPM）

```js

  colonyIn   : 2.34,   // ·  主标落在波front后面

  labelIn    : 8.00,   // ● bar 5
  convStart  : 8.70,   // ·

  sweep      : 12.42, recede: 13.20,                     // ·

  breakdown  : 16.00,  // ● bar 9  撤鼓，场退到底噪
  drop       : 18.00,  // ● bar 10 场重燃，全部归位
```

## 四、关键实现参数（1920×1080 基准，S = sqrt(W·H/(1920·1080))）

- **网格**：cell = max(48, 64·S)。列线按分区着色、行线中性灰——只有列承载
  色彩扫描，波才读得出方向。空网格列 alpha ≈ 0.145·gridE，行 ≈ 0.075·gridE。
- **两条独立能量通道**（关键）：`gridE`（规则线，第 0 帧就可见）与
  `nodeE`（被认领的节点，波到之前恒为 0）。**合成一条会让①和②分不开**。
- **波**：`R = eOut(seg(t,burst,burst+1.25)) · HALFDIAG · 1.35`，
  带宽 `BW = HALFDIAG · 0.115`。节点认领判据 `cl((R-d)/(BW·0.55))`，
  **不要加正偏置**（加了会全场预亮，波就消失了）。
- **点火闪**：`ig = exp(-((d-R)/(BW·0.9))²)`，alpha += 0.75·ig，尺寸 ×(1+1.9·ig)。
  这个"经过时炸一下"才是"被认领"的读感来源，只靠亮度渐变读不出来。
- **字标汇聚**：离线用 Python 按归一化坐标采样字标 alpha 成 `cells.js`
  （156×32 网格 → ~1100 格），运行时按目标宽高缩放，一张表吃所有画幅。

## 四之二、把人放进场里（2026-08-16 第二支片新增）

奖池片里客户提议"把 12 位 KOL 头像放进网格，光波扫过时闪现"。**这不是外挂效果，
是构思的字面化**——片子说"每个亮起的节点是一个上榜的人"，节点里真的出现人脸。
凡是用这个配方又需要"人"的场合，直接复用：

- **头像不能是节点尺寸**。节点 5–14px，脸糊成一团。单独一档：约 2 个格宽
  （1920 上约 110px），才认得出。
- **不能真的只闪一瞬**。方块 0.1s 就读得到，人脸要约 0.7s 才"注册"，低于这个
  数观众只觉得画面抖了一下。做法：**平时极淡地一直在**（0.014，比最暗的网格
  节点还低），波扫过抬到 0.65 再落回。读感变成"这些人一直在场里，光波只是照亮
  了本来就在的"，比"突然插进来几张脸"高一个层次。
- **描边要跟着一起压**。实色品牌绿在同样 alpha 下比照片显眼得多；只压脸不压圈，
  脸暗下去了圈还亮着，更奇怪。ring alpha 挂 lift：`a*(0.18+1.05*lift)`。
- **每个文字块都要有自己的避让椭圆**（标题/数字/尾部 CTA 各一个），少一个就会有
  张脸落在文字后面。
- **"N 个必须全在"要用枚举法，不能用随机试探**。原本是随机撒点+重试上限，
  放不满会**静默少放**——成片里根本看不出来少了谁。改成先枚举全部合法交叉点、
  按半径分带选满，放不满直接 throw。渲完还要在浏览器里实测
  `KOL.length / kimgs.filter(complete).length / 去重坐标数` 三个都等于 N。

**素材来源**：头像名单必须来自**本场活动**的权威数据源（由用户提供或确认），
不要沿用上一场活动的名单——不同活动的出席者往往只部分重合，直接套用会
**对外宣布错误的出席名单**。

## 五、踩过的坑（都付过学费）

| 症状 | 原因 | 修法 |
|---|---|---|
| `getImageData` 抛 tainted canvas，整片渲不出 | file:// 下 canvas 画过本地图片就被污染 | 离线 Python 采样成 `cells.js`，运行时不读像素（§7.4 本来就是这么建议的） |
| 冲击波读不出来，像个蓝光斑 | 闪光层 0.62 太亮，把网格盖住了 | 闪光压到 0.20——冲击要读成**网格点燃**，不是镜头光晕 |
| 波 0.7s 就扫完，眼睛跟不上 | 行程 0.95s + 1.5 倍半对角线 | 拉到 1.25s / 1.35 倍 |
| 开场两秒像黑屏 | 只有网格线没有主体 | 补中心呼吸种子点（同时是波的起源），带柔和 halo |
| contact sheet 上网格全看不见 | 缩到 480px 把 1px 线吃掉了 | **在全分辨率下判断细纹理**，别在缩略图上下结论 |
| 以为数字落错位（$40,000 显示成 $42,222） | **Orbitron 的零是斜杠零 Ø**，缩略图上像 2 | 不是 bug。字体没有无斜杠替代零（ss01/ss02/ss03/salt 实测全一样）；**但字距要给足 0.085em**（该字体侧边留白≈0），0.02em 时斜杠会跟邻字黏成一片 |
| 后补的 `+` 让整组数字偏离中心 37px | `+` 元素**始终占 flex 宽度**，所以没出现时数字已被挤左；补偿位移还写反了方向 | 隐藏时把整组**右移**半个 `+` 宽，随 `+` 出现缓动回 0：`translateX(plusW/2*(1-pp))` |

## 六、配乐配套（同一份 T）

- 三个锚点各一记 impact：burst / lock / drop；lock 另加 chime。
- 汇聚段 16 记 tick，音高沿视觉缓动爬升。
- **每小节编排写成显式表**（`ARR`），因为 RMS 形状本身是交付物：
  bar 9 必须是全曲最低、bar 10 必须最高。散在条件判断里调不出来。

### 混音踩坑（第一版被客户指"有复杂的噪音、刺耳"）

真实原因不是某个频段尖，实测频谱 2–5kHz 只占 2.4%。三个真因：

1. **方波 pad**：`np.sign(sin())` × 3 detune × 3 和弦音 = 18 个粗糙振荡器互相拍频，
   4 阶低通挡不住方波谐波 → 读作噪音。**改纯正弦堆叠**。
2. **声部音区太低**：和弦全在 164–294Hz、琶音顶到 590Hz，整个编曲挤在最浑的
   低中频。**整体升一个八度**（低频占比 58% → 28.5%），sub bass 单独守低音。
3. **压得太满**：tanh 硬推 + 峰值归一到 0.95 → RMS 0.431（约 -7dBFS）。
   **改成按目标 RMS 归一（0.135）+ 只对峰值软限**，峰值 0.698。

> 通则：听感"刺耳/噪"先量频谱再动手。这次量完发现是**闷+挤**不是**尖**，
> 凭感觉去砍高频只会让它更闷（案例中就这么错过一轮，800Hz 以上砍到只剩 1.2%）。
