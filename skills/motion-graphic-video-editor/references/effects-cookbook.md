## 7. 效果配方库（按类别归纳，全部确定性、全部实战验证）

> **⚠️ 进入本节前必须先完成 §4.7 构思定稿。**
> 本节是**取材库，不是菜单**——不要通读一遍然后挑几个好看的用。
> 每取一个配方，先回答"它如何服务于我锁定的那个构思"；答不出来就不用，**即使它很好看**。
> 从目录里挑零件拼装，正是成片"有配方没构思"的直接成因。

### 7.1 文字类

- **渐变扫光 reveal**（"高级感"的来源）：每字 span 四通道同步——opacity + 色彩(品牌色→纸白) + translateY(14px→0) + blur(6px→0)，软边 EDGE≈行宽 30%（更窄像擦除，更宽像整体淡入）。模式：`hot`(品牌色落白，金句用) / `spectrum`(保持品牌色，URL/数字用) / `none`。只做 opacity 显得廉价，四通道成本相同。
- **整块渐变扫光**（数字落位后的奖励，模式 B）：品牌色→白线性渐变左→右扫过整块字形 ~0.4s。是文字的渐变**填充**（background-clip:text）不是叠光斑；**所有字形共用同一条渐变**（同 backgroundImage，backgroundSize=整串宽，backgroundPosition 按各自偏移取负），否则是六道扫光不是一道。全片只用一次。
- **逐字扫描文案**：~40 字符/秒，字符间隔 25ms，三通道同动；多行错开 0.05–0.13s。
- **逐词点亮**：已读词亮、未读词暗——"正在被说出"的节奏，权益行专用。
- **顺序列表逐项落位**：icon + 序号 + 词的行，每 bar/2 拍落一行，落位时 icon 上一次小 impulse 闪；**每行分配一个品牌色**（色板有 N 色、列表有 N 项就按序用满整条光谱）。
- **Decode / scramble**：字符循环随机字形后从左到右锁定（每 ~0.115s 一个）。**乱码池用品牌 Logo 切出的字形**，中间帧也全程 on-brand；随机用确定性 hash（`(tick*2654435761 + i*40503)>>>0`）不用 RNG；槽位按源图**字符中心**定位。配 ~30Hz click 纹理 + 每字一声递升 chime。
- **打字机块**：小方块沿字宽插值飞行，每字锁定 dip 一下；字位用 span offsetLeft 实测，别按等宽估。
- **品牌字形卡**：整屏单字母卡（共用垂直带裁切），每张 1s 硬切节奏；0.5s 太快读不到配词。
- **卡片里出现品牌名时用 Logo 图不用字体排**——用户第一轮必提。

### 7.2 数字类（两种滚法按模式选）

- **老虎机计数器**（模式 A/D，spin→lock 一次到位）：90 格数字列 translateY；落位目标 = `wholeTurns*10 + targetDigit`（别的算法都会落错位）；**各位圈数不同**（如 3 圈/6 圈）落位速度才不同，像真机械；窗口 = 1.30× 格高 + 居中偏移（1 格窗硬裁邻位）；**掩罩羽化宽度挂转速** `fw=(1-spin)*0.19`（固定掩罩会压暗已锁数字，无掩罩露邻位鬼影）；运动拖影 `blur((1-spin)²·22px)`（平方才收得干脆）；锁定时双层滚轮（品牌渐变/纸白）0.3s 交叉 + 5% 过冲 pop。
- **里程表滚轮**（模式 B，开场大数字）：每位独立 130 格循环滚轮向上推进；**每位有自己的落位时刻**从高位到低位依次锁定（共用一个缓动会让指数尾巴半格悬停，像坏了）；**模糊由真实速度驱动**——位置写成纯函数，相邻帧差分出速度 `blur=clamp(v)*17S`（用 1-进度当模糊量是错的：进度 0.9 时线速度还很高，画面是一排清晰乱码）；窗口 = 格高×1.04；静态字符（$、逗号、+）不滚直接排间。
- **科技字体两个坑**：Orbitron 类侧边留白≈0，字符位置必须按**前缀宽度**算（`x_i=measure(text[0..i])`）+补 ~0.085em 字距；后出现的符号（如后补的"+"）出场瞬间让主体同步左移半个符号宽，收尾才视觉居中。
- 数字字体是气质的一半：出 6 字体对比静帧让用户选（几何/techno 读作 digital；DSEG 七段管读作时钟且 `1` 是光杆）。

### 7.3 Logo / 3D 类

- **3D 挤出 Logo**：~40 层 slab 逐层 translateZ（step ≈ 显示宽 0.30%，总深 ≈12%），亮度斜坡 **0.58→0.18** 带冷色调 `(0.74,0.82,1.04)`（斜坡低于 ~0.18 侧壁隐形）；perspective `1500·S`；旋转 −48° 落 **−13°**。四大陷阱：preserve-3d 子树内**任何** blend-mode/群组 opacity≠1/filter 都会静默压扁整个 3D（opacity 0 也会！）——淡入淡出放 3D 树之外的祖先；细线条/副标不挤出（会梳齿条纹），平贴 front 层；expo 缓动会让揭示还没看清就结束；宽图旋转后透视放大近端 ~7% 会切边（竖版控制 ≤78%W，验证要看**落定角度**那帧）。
- **修饰**：specular 扫光（白渐变 masked by logo alpha，3D 内用 normal-blend 半透明，**不用** screen）；背后两个品牌端色 rim 光把 Logo 从黑里托出来。地板倒影通常**不值得**——像污渍。
- **Burst 冲击帧**：三层预渲染——光谱环 PNG（0.10→1.00 eExpo 0.34s 再缓漂）+ 热核心（0.34→2.1 缩放、0.55s 内消失）+ ~16 条渐变 streaks（screen blend、种子化随机延迟）+ ~30 片品牌形状 debris + 一次 imp 径向闪光 + **同帧一声音频撞击**。
- **信号脉冲**：对特定 Logo 元素做短暂亮度/缩放/drop-shadow 脉冲，与色波同拍。

### 7.4 变身 / 重组类（模式 C 核心）

- **像素网格采样**：源/目标画作采到**同一张**方格网（锚定目标 Logo 构造单元 u），保留 coverage ≥0.4 的格子，存 JSON `{canvas,cell,target,source,map}` 以 `window.__CELLS` 载入。
- **源→目标匹配**：按*各元素 bbox 内归一化位置*匹配（KD-tree），**不按全局排名**——排名映射会把字形飞行中撕碎；bbox 归一化让 "C 落到 C"，飞行途中文字仍可读。
- **无祖先的新格子**（map=-1）：从画外 360° 随机射线飞入（半径 2.5–4× 画布）带轻微切向卷曲——读作"蜂群汇聚"；**全程穿新形象的颜色**（它们是新事物到来，不是碎片；灰色冒充者读作 debris）。
- **无人认领的源格子 = debris**：保留（碎裂的原体才无洞），然后外爆淡出于揭示之前。
- **块碎裂**：碎前 impulse 抖动预震，再按 x 位置错峰飞行（如右→左），词像波浪回流不是暴徒散场。
- **格子飞行**：位置 eInOut + 正弦钟形弧线/升力/旋转/缩放 dip + 落地 pop impulse；颜色在**各自飞行中点**后旧→新交叉。
- **生长/殖民**：按离种子距离出生 `birth = t0 + span*pow(d/dmax,0.85) + jitter`，back-eased 缩放 pop，出生时亮、落定回归本色。
- **冲击波网格**：全屏小方格场（~1300 格 @38px pitch），高斯亮带 `exp(-((d-r)/w)²)`，r 按 eOut 扩张；带宽取半对角线 14–20%（读作"场被接管"；太窄像描边）；多波 = 每个品牌色一波，**整拍间隔**（2 拍有仪式感，<0.4s 读作闪烁——真实用户意见）；Logo 周围留椭圆豁免区，波不洗过主标。
- **残留场**：末波后网格留 5–9% 透明度微光（去饱和、逐格随机、豁免区内更弱）——"殖民地留下了"。
- **CRT/8-bit 套件**：3px 扫描线缓滚（multiply）、撞击帧 ±5px 单帧水平 kick（一上一延迟下两个 impulse）、像素点阵背景慢漂。
- 格子实际尺寸 ≈ 网格 pitch ×1.12（正好等距会出发丝缝）。

### 7.5 转场类（按模式取用）

| 手法 | 做法 | 适用 |

| 黑场硬切 | 收黑层 3 帧尖峰；跨切钉住 match-hold 元素 | A/C/D |
| 重叠溶解 | 退场：放大 ~112% + blur 0→18px + 淡出；进场：位移步长递减；重叠 0.35s | B |

### 7.6 产品演示 / 真实录屏类

- **设备框**：CSS 画机身（渐变金属轨、内黑轨、圆角屏、灵动岛、侧键），屏内 `<canvas>` 逐帧绘制录屏序列——**绝不用 `<video>`**（非确定性）。
- **Playlist 映射**：`[filmStart, filmEnd, sourceStart, rate, zoom?, panFrac?]` 表把影片时间映射到素材时间——每个功能词落位的瞬间正好出现对应界面；rate<1 慢放拉长短素材；zoom/pan 推进特定 UI 区。
- **相机三层结构**：`相机层(推拉平移) → 入场层(升起/退场) → 机身层`，各管一件事；**每层显式宽高**（塌成 0×0 会带偏缩放原点）。相机写关键帧数组 `[时间,nx,ny,zoom]` easeInOut 插值；把 (nx,ny) 推到画幅中心的平移 = `-z*(n-0.5)*屏幕尺寸`。
- **重点信息真的推进去**：全片最大 zoom 给最重要的卡，占画幅宽 90%+，停足 1.5s；推进深度按画幅反推（`ZMAX=目标宽/卡片实际宽`）不写死倍数；相机移动作用在设备组（~5%/几秒的缓推读作运镜）。
- **点击反馈**：白色圆环涟漪扩散淡出 0.3s，不做手指不做光标。底部弹层：面板上滑同时**底层缩 94% 压暗 55%**（底层不动就穿帮）。
- **画内修图**（素材数值与文案冲突时）：定位文字像素盒 → 亮度测试找出含它的帧 → 采样两端背景渐变色盖掉旧字 → 同字体同字高同渐变 8× 超采样重画新字，Lanczos 降采样。显示尺寸下不可见。**做了必须告知用户并说明原因。**

### 7.7 背景 / 氛围类

- **预渲染辉光 PNG 边界契约**（critical）：画在**加 padding 的画布**里；加硬径向窗强制外圈精确归零（如 `1-smoothstep(0.42,0.485,r)`)；**任何 blur 后重新套窗**（blur 会把能量推回边缘）；打印四角+边中点检查必须 [0,0,0]（"看起来黑"通常还有 15–120/255，screen 混合下暗场露方框——真实翻车："圆形效果有个方形的外框"）；显示尺寸按 padding 系数放大回去。资产套装：ring / ring_soft / core / bloom。
- **光谱环接缝**：conic 渐变首尾相撞（橙→青经过脏绿）——光谱只铺 ~86% 圆周，回程弧压暗当"背光面"。
- **景深粒子隧道**：品牌形状当粒子（~18% 带字形、~32% 只描边），**JS 自算透视**（`sc=PD/(PD-z)`，DoF 需要容器 filter 而容器 filter 会杀 preserve-3d）；DoF 用**深度分片容器**：10–16 个 div 各一个固定 blur，粒子换桶才 reparent（120 次 blur/帧 → 12 次，1fps 与 2.5fps 的差距）；远→近绘制保遮挡；两端 smoothstep 淡入防 pop；爆发时整容器一个 motion smear，绝不逐元素。**spawn 区间与 wrap 距离同一常量**，否则粒子丢一半。
- **廉价质感件**：四角 corner brackets（随内容淡入淡出）、光谱分隔条（品牌色序圆角条 scaleX 0.2→1）、像素点场（radial-gradient 平铺 ~46px、1.7px 点、16% 透明度慢漂）。

### 7.8 收尾类

- **坍缩留黑**（模式 B 唯一冲击）：品牌收尾前光晕先冲到最亮（imp +55%）再 0.4–0.45s 内坍缩近全黑（同时缩到 0.22）。没这口"吸气"，尾板没有决断感。
- **分步信息卡**（"结尾太挤"的标准解法）：一次一条消息，同一屏位轮播，每张 **2–3s（2s 是地板）**；mono 小标签 + display 大值；退场上移+淡出不硬切；mini lockup 钉在上方品牌不断线。用户嫌挤时**拉长影片**，绝不压缩卡片。
- **尾板**：logo 6% 过冲弹出后整组 -3%/s 缓缩；信息分层错峰进场（logo→分隔条→日期→URL，间隔 0.15–0.4s）；一屏最多三行，放不下就砍或分卡。
- **Logo 独立签名收尾**：尾板经黑退出 → 主标独自淡入纯黑上（先清掉所有辉光）→ 停 ~2.5s → 淡黑。若要"尾板缩、主标放"对冲淡出：尾板三件套溶出、主标重叠 0.1s 接上、缓慢**放大**着淡出——方向相反才有层次。配乐必须在其下衰减（§9）。
