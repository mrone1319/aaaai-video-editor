# 修改意见路由表（§11）

**攒一轮意见一起改**（每轮 = 一次完整重渲），改完先 contact sheet 再全量。用户的批注是症状不是病因（"v1 更好"曾经指一个辉光方框 artifact）——先复现、看单帧、找真实缺陷。**用户说"只改这两处"就只改这两处**，不夹带优化。

| 批注 | 动作 | 成本 |
|---|---|---|
| 文案/数字/日期/URL/字体/色板 | 顶部常量一行改 → 局部补渲 | ~1 分钟 |
| "太赶 / 想多停一下 / 让它呼吸" | **加整小节拉长影片**（绝不压缩别的段），配乐同步重生成 | 一次渲染+配乐 |
| "太挤"（尤其结尾） | 拆分步卡片同位轮播，每张 ≥2s | 一次渲染 |
| "再强一点 / 多点效果" | **先别加效果**——多半是构思（`concept.md`）不够强，不是效果不够多。优先做法：让贯穿性载体在这一段**换一种更大的形态**（例：光点→充满画面），或加大对比（暗场更暗、亮场更亮、静止更久）。确实要加时，只加服务于构思的事件，保住唯一高潮 | 一次渲染 |
| "太多 / 太快"（重复性效果） | 减事件数、整拍间隔、加宽单事件时长 | 一次渲染 |
| "字体普通" | 换品牌 Logo 切出的字形 | 一次渲染 |
| "这里字换成 Logo" | 文字层换 Logo img 层（预留槽位则零结构改动） | 一次渲染 |
| "X 应该从别处出现" | 换出生模型（画外射线/种子生长），数据层改动，飞行代码不动 | 一次渲染 |
| "之后留一点痕迹" | 残留场 5–9% 透明度 | 一次渲染 |
| "别淡出" | 去收黑，主体全强度 hold；配乐仍要衰减和弦收尾 | 一次渲染 |
| "前 N 秒 Logo 出现两次" | 平面版与 3D 版做交接（先出场者让位退出），不共存 | 局部补渲 |
| 主观二选一（字体/颜色/风格） | **渲对比静帧给用户选——show, don't argue**（一张图几秒 vs 一次全渲十几分钟） | 一张静帧 |
| 局部 3 秒内视觉修正 | `--out` 帧目录 ＋ `--at` 区间补渲 ＋ `encode.sh` | ~1 分钟 |
| 「动作太平／没力」 | 看能量曲线（`check_motion`）：死时间加镜头呼吸、视差、错峰；缓动换有重量的（`MG.spring`、`snap`）；先在播放器里实时调 | 一次渲染 |
| 换尺寸 | 同工程改 w/h 重渲（+3 帧 LAY 微调抽查） | 一次渲染 |
| 改片长 | 真实配乐：`music_grid.py fit --dur` 重挑段落、更新 `MUSIC`；合成配乐：场景＋配乐两文件同改 | 一次渲染+配乐 |
| 新录屏素材 | 重抽序列、重映射 playlist、补渲相关段 | 局部补渲 |
| 新增独立段落（如 logo 独立收尾） | **必须占新增时长**，硬塞会压死原有段落的呼吸 | 一次渲染+配乐 |

付过学费的通则：① 第一版永远太挤太快——从一开始按 1.5× 时长预算、分步卡片化设计；② 品牌自有字形/Logo 永远优先于替代字体；③ 参数化一切用户叫得出名字的东西——最终全会被要求改。
