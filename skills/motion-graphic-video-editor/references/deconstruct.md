# 参考片拆解（§3）

目的不是抄帧，是**提炼可迁移的结构**——段落、节奏、冲击点位置。拆完先给用户看，再动手。

## 1. 一键分析

```bash
$PY "$SK/analyze_reference.py" ref.mp4 --out tmp/ref
$PY "$SK/check_motion.py" ref.mp4 --out tmp/ref/energy.png      # 参考片的能量曲线
```

`analyze_reference` 产出：`meta.txt`（规格）、`sheet.jpg`（全片 contact sheet，先看这张）、`frames/`（高清抽帧）、`loudness.txt`（每 0.5s 响度＋瞬态）、`cuts.txt`（逐帧场景分数＋亮度，并分类）：
- **HARD CUT**：场景分数高**且**亮度跳变——真正的剪辑决策；
- **CONTENT**：场景分数高但亮度不变——解码乱码、快速动画，不是剪辑。

能量曲线（每秒运动量）：峰＝事件，谷＝呼吸；看峰在哪（前段爆发？中段？）、峰谷比、有没有绝对静止的尾板。

## 2. 两条方法铁律（各付过一次错误结论）

1. **任何「结果为 0／为空」的检测，先证明管道确实读到了数据。** ffmpeg 的 `metadata=print` 配 `-v error` 会静默什么都不印，看起来像「零硬切」这种干净结论。脚本会核对「收到的分数条数 ≈ 总帧数」，不够就停。
2. **只有硬切值得做卡拍统计**，容差远小于网格间距一半（±0.03s），并先算随机期望再相信「命中」。帧差能量峰是动画运动的副产品，不是剪辑决策。

## 3. 输出「剪辑公式」

按时间码列段落表（段名／画面事件／亮度／音频事件），压缩成：**一个 `T` 时间轴常量 ＋ 一条亮度／色相曲线 ＋ 几条铁律 ＋ 那一个构思**（`concept.md`）。多数短品牌片是五拍结构的变体：

**tension（引信 1–2s）→ burst（一次冲击）→ payload（核心信息／数字）→ breath（低亮段＋一句话）→ resolve（Logo＋CTA）**

**参考片只有一次冲击的，你加第二次就俗了。**

## 4. 可迁移法则（实测反复成立）

1. **低亮段放内容，不放空黑**：一句标语、一个功能切换、"This is X."。黑场有两种：**呼吸**（画面静、音乐继续推）与**断章**（音画同时挖空，要观众重新聚焦）——按用途选。
2. **一个贯穿性元素兼任多职**（背景、转场笔、光源、容器）是统一感的来源；但它**不负责**转场——段落之间该切就切，平滑感来自设计系统统一，不是来自不敢切。
3. **前景／背景双层景深**：近景层有失焦元素、偶尔飞出画框——2D 合成像实拍的最便宜手段。
4. **数字要「滚」不要「跳」**：纯数字镜头 1.1–2s；各位滚不同圈数、高位先锁（`MG.counter`）；锁定那一刻对拍。
5. **逐字动画的节奏 ＝ 音效 onset 的节奏**：先做字，再按字的进入帧铺 tick。
6. **尾板**：品牌标独立出现＋保持（≥1.5–2s）＋音画同步淡出，占全片 8–13%。短片可绝对静止，长片先微动再定格。
7. **匹配保持（match hold）**：跨段切换时钉住一个元素（通常是 mini lockup），品牌存在感不断线，全片才是一体而不是幻灯片。
8. **卡拍是逐片、逐刀的选择**：锚点卡得极准，其余由内容决定（`timing.md`）。
