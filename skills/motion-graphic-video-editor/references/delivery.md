# 渲染、编码与交付（§10）

## 1. 渲染

```bash
# 抽查静帧（几秒）
$PY "$SK/render_frames.py" --scene scene.html --dur 24 --out tmp/check --at 1.9,4.2,6.6,9.6,12.4
# 动态预览（960 宽 30fps，几秒到一分钟）
$PY "$SK/render_frames.py" --scene scene.html --dur 24 --preview --video tmp/preview.mp4 --audio out/score.wav
# 全量（后台跑，轮询 render.log）
nohup "$PY" "$SK/render_frames.py" --scene scene.html --w 1920 --h 1080 --fps 60 --dur 24 \
      --video out/film_16x9.mp4 --audio out/score.wav --mblur scene > render.log 2>&1 &
```

- **GPU（Metal）＋自动 4 个 worker**，直接出 MP4，每个 worker 的分段逐一核对帧数、无损接起来。`--cpu` 退回软件光栅（慢 ~5 倍）；一支片从头到尾用同一种。
- 场景引用了上层文件夹的东西（例：`../assets/`）时加 `--root`，让本机服务器包住它们。
- **运动模糊**：`--mblur scene`（只在 `MG.blur(a,b)` 宣告的区间）或 `--mblur auto`（自动找快速移动的帧）。快门内多子帧平均，慢的 8 个、快速甩镜自动加密到 64；前向快门，切点不会被糊。
- **局部补渲**：改了 3 秒内的画面，用 `--out frames/L --at <那段的逐帧时间>` 覆盖同名帧，再 `encode.sh` 重编码（~1 分钟）。需要逐帧文件或透明图层时才用 `--out`。
- **多画幅**：同一场景换 `--w/--h`；改过共享代码后**所有画幅全部重导**。
- **配乐**：比影片短会补静音、不会截片（并警告）；比影片长按画面长度切。
- 实测速度（M2）：55 秒 12 场的 showreel（含 3D、7 000 粒子、运动模糊）1080p60 约 160 秒；8 秒动作示范 22 秒。

## 2. 编码后必验

`nb_frames == dur × fps`（渲染器会自己核对并在不符时报错退出）、音视频时长一致、`ffmpeg -v error -i out.mp4 -f null -` 完整解码。兼容降级版：`-profile:v baseline -level 3.1 -vf "scale=720:1280,fps=30"`。

## 3. 交片前七查（缺一不发）

1. 转场纪律符合模式（B：`analyze_reference.py` 测成片硬切数为 0；A/C/D：冲击次数 ≤ 设计值）。
2. 帧数 ＝ 时长 × fps，音视频同长。
3. `check_motion`：没有未宣告的死时间、跳变；字够大、都在安全区。
4. 黑场：应黑的帧亮度 5–12（不是 0，也不是漏光）。
5. 静音可读：关声音看一遍，节奏纯视觉成立（社媒自播的前提）。
6. 数据一致：大字数字／日期／URL 与界面素材、与用户确认的逐字一致。
7. 多版本同源：所有画幅都是最新代码渲的。

## 4. 平台尺寸与安全区（2026）

| 目标 | 尺寸 | 备注 |
|---|---|---|
| Web / YouTube / 大屏 | 1920×1080 | |
| IG feed / 轮播 | 1080×1350 (4:5) | 网格缩图裁 3:4 → 关键内容留在居中 ~1012×1350 |
| Reels / TikTok / Shorts | 1080×1920 (9:16) | **双重安全区**：网格裁 3:4（y 240–1680）∩ 平台界面遮挡（上 ~200px、下 ~400px）＝ **1080×1120, y 400–1520**。Logo、大字、关键数字留在区内；特效可出血 |
| X / 方版 | 1080×1080 | |

**每支片至少一个封面级帧**：≥1.5–2s 稳定停留（`MG.hold`）、核心元素在安全区、缩图可读、不在特效中段——同尺寸 JPG 随片交付。

## 5. 交付包

- 每尺寸一个 MP4（帧数验证过）＋ 2–3 张海报帧（封面＋一张动作中帧）。
- 需要时：静音版；**透明图层**——`--alpha` 渲 PNG 序列（场景要配合 `alpha=1`，`authoring.md` §10），下游多数直接要 PNG 序列；要独立文件才用 `encode.sh --alpha` 封 ProRes 4444（`.mov`）——**不要用 VP9/WebM 封透明**。
- 一两句话说明改了什么＋**明说哪些参数是一行改**（文案／日期／URL／数字／尺寸／时长）；任何自主判断（默认风格、画内修图、加拍）都要披露并给替代选项。
- 命名 `{project}_{duration}s_{aspect}.mp4`；大文件传不过去时给小体积兼容版。
- 整支动画要上字幕、统一响度、做封面时，交给 aaaai-editor（`SKILL.md` 末节）。
