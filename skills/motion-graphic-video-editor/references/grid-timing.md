### 5.2 定 BPM 与时间轴

- 定 BPM。**120 BPM（beat=0.5s，bar=2.0s）是 promo 通用默认**；紧张倒计时 ≈128+，抒情 ≈90。
- **★锚点卡拍，其余由内容驱动**（2026-08 实测修订，见下方说明）。片长仍凑整小节数（16/18/21/24s…）。
  - **锚点**（全片就那 3–5 个：唯一的硬冲击、数字锁定、drop、尾板进入、Logo 落定）**必须精确卡在 beat/bar 线上**——
    实测高完成度作品的锚点能做到差 0.002–0.026s 的帧级精度，这是"制作水准"被读出来的地方。
  - **其余所有事件的时间点，由内容本身决定**：句子讲完的那一刻、数字滚停的那一刻、
    眼睛读完最后一个字的那一刻、物体落定的那一刻。**不要把这些时间戳四舍五入到网格上。**
  - ⚠️ **不要用随机抖动伪造"人味"**。真实作品里没卡拍的刀是被内容推着走的，不是随机偏移的；
    随机 jitter 读起来是**邋遢**，不是自然。网格是**参照物，不是磁铁**。

> **为什么改这条**：初版写的是"每个视觉事件落在 beat/bar 线上"。
> 实测四支高完成度参考片（`references/formula-library.md`）后发现这条不成立：
>
> | 片子 | 硬切与拍位的距离 | 统计检验（±0.03s，按网格间距折算随机期望） |
> |---|---|---|
> | JUP Offerbook | 12 刀，**0.007s 到 2.399s 都有** | 3/12 命中，期望 3.0 → **与随机无异** |
> | JUP Pick a Pack | 4 刀 | 3/4 命中，期望 0.8 → **显著** |
>
> 结论：**卡拍与否是逐片、逐刀的选择，不存在"全部卡拍"的通则。**
> 而"每个事件都卡拍"这条指令会让时间轴常量退化成 BEAT 的整数倍序列
> （`2.00 / 5.50 / 7.50 / 10.00 …`），产出节拍器般的规整感——
> 这正是成片被评价为"很 AI"的一个直接来源。
>
> 详细数据与统计方法见 [`references/jup-pickapack-case.md` 第四节](references/jup-pickapack-case.md)。
- 时间轴写成场景文件顶部**单一常量对象**，所有渲染函数只引用它；**配乐脚本逐字复制这份常量**——音画同步是查表算术，"改时长"永远是两个文件的编辑（场景+配乐），片比音乐长是观众第一个发现的缺陷。

```js
const FPS = 60, DUR = 24.0, BEAT = 0.5, BAR = 2.0;
// ● = 锚点，精确卡拍（帧级）    · = 由内容决定，不吸附网格
const T = {
  burst:     2.00,   // ● bar 2 downbeat — 全片唯一的硬冲击
  numIn:     5.47,   // · 数字开始滚（承接上一句念完的那一刻）
  lock:      7.50,   // ● 数字锁定 = 锚点
  cardOut:   9.83,   // · 卡片退场（读完最后一个字）
  moneyLock: 20.50,  // ● 全片最响的一拍，落在小节线上
  sting:     22.34,  // · 收尾扫光（承接上一动作落定）
  end:       DUR,
};
```

注意上面**故意不是**一串 0.5 的整数倍：`5.47 / 9.83 / 22.34` 这几个值来自内容时长
（一句话念完、一行字读完、一个动作落定），不是随机凑的小数。
写 `T` 时先问"这一刻在内容上意味着什么"，再决定要不要把它拉到拍线上。

各模式验证过的模板骨架（可整段增删小节）：

- **A · 35s / 18 bars**：tension(0–2) → burst(2) → lockup(4.2) → 数字滚动锁定 bar5(6–8) → 标题/分隔/日期(8.5–9.6) → 字形卡×4 每张 1s(12–16) → 黑场金句=breakdown(16–19.5) → 3D 揭示=drop(20) → decode(21.4) → 信息卡×3 各 2–3s(23.7–31.3) → 黑 → logo 独立收尾(32–35)。
- **B · 21.5s**：里程表数字(0.1–1.5) → 扫光(1.8) → 交接产品(3.3) → 演示推拉、最重推进在小节线(9.4–10.4) → 逐字文案(12.45) → 坍缩留黑(15.5) → 尾板(16–21.5)。
- **C · 10s / 5 bars**：bar1 seed+riser → bar2 旧形象成立 → bar2.5 break 碎裂 → bar3 迁移 → bar3.75 breakdown+riser → bar4 **drop 新形象锁定** → bar4.5–5 色波脉冲 → bar5 hold。
- **D · 24s**：钩子问句(0.5) → 3D 主 Logo+标题(2.6) → 联名 beat(3.45) → 唯一黑场呼吸(5.0) → 数字滚动(5.6–7.6) → 权益三条(8.6) → 白溶解(11.0) → How-to 卡×3 各 1.7s+(11.6–16.7) → CTA 长驻(17.0–20.5) → 色块擦除(20.6) → 联名尾板(21–24)。
