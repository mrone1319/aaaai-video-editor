# Swiss／编辑风格系统（创意编程 showreel、设计工作室片、科技品牌片）

> 用在「排版就是主角」的片子：模式 H（showreel）、设计系统发布、科技／设计品牌片。
> 起步件：`assets/styles/swiss.css`（色彩与字级变量）＋ `mg-kit.js` 的 `MG.grid`／`MG.clip`／`MG.swap`／`MG.zoomTo`／`MG.marquee`／`MG.hit`／`MG.wave`。
> 示范：`examples/showreel/`（每一条规则都在里面用过）。

## 1. 色彩：严格的四色系统

| 角色 | 默认 | 用法 |
|---|---|---|
| 墨 ink | 近黑 `#0D0D0E` | 字、线、反转后的底 |
| 纸 paper | 暖白 `#F2EFE8` | 大部分场景的底（不是纯白，纯白看起来像网页） |
| 重击色 | 钴蓝 `#2340FF` | **只用来铺满全屏**做节奏重击，一支片 1–3 次 |
| 点缀色 | 荧光绿 `#D4FF3A` | 每场最多一两个元素（一颗粒子群、一条线、一个数字），**不当底色停留** |

- 品牌有自己的色就替换，但**数量不变**：两个中性色＋一个重击色＋一个点缀色。多一个颜色就开始像模板。
- 反转（黑白互换）用 `MG.swap`，**在同一帧硬切**，不要渐变——渐变读起来是「网页过场」。

## 2. 字：极端的大小对比

- 超大无衬线粗体（`.sw-display`，220–420px＠1080p，行距 0.82、字距 -0.045em）对上极小的技术标签（`.sw-label`，13px 等宽大写）——**对比至少 1:15，越大越好**。中间尺寸（40–90px）少用，它是「网页正文」的尺寸。
- 大字可以**冲出画面**：裁切本身就是构图（加 `data-bleed`，能量验收不会报超出安全区）。
- 技术标签永远带信息：编号 `03 / 12`、坐标 `X 0.618  Y 0.382`、时间码 `00:14:07`、参数 `SEED 4127`、单位 `n = 2 048`。纯装饰的假字（lorem）一律不用。标签加 `data-deco`（它是质感，不需要能读）。
- 中文：标题用粗黑体（苹方粗／思源黑体 Heavy），技术标签仍用等宽英文数字；不要把中文字距拉宽。

## 3. 构图：模块网格＋非对称

- 先 `MG.grid({cols: 12, rows: 8})` 定网格，所有元素落在格线上；**不要把东西放画面正中**（正中＝PPT）。
- 典型版式：超大字压在左下 3/4、右上角一组小标签；或一个元素只占 2×2 格，其余全是留白。
- 留白至少占画面一半；一个画面只有**一个**主角。
- 细线（`.sw-rule-h/v`）用宽度从 0 长出来的方式出现（`MG.at`），像在「画」版面；十字定位标记（`.sw-cross`）放在格线交点。
- 可以把网格本身画出来（`g.lines()`）当作一场戏：网格展开 → 内容落格 → 网格消失。

## 4. 动作：快慢对比、图形化转场

- **慢**：3D 雕塑、粒子、网格展开，用 `smooth`／`read`，3–6 秒。**快**：字的出场与转场，0.15–0.4 秒，`snap`／`expo`／`whip`。同一支片两种速度交替才有节奏。
- 转场优先序：**硬切**（同时反转颜色）＞ 裁切擦除（`MG.clip`）＞ 推进穿越（`MG.zoomTo` 推进某个字或格子，在里面切到下一场）＞ 版面变形（`MG.rect`：格子扩成全屏）。
- 字的动作：遮罩滑出（`MG.reveal` mask）、逐字错峰、整行横向跑字（`MG.marquee`）、重击放大落定（`MG.hit`）、字体网格的波形变化（`MG.wave`）。
- 数字：计数器滚动后**锁定**，锁定那一帧对拍。

## 5. 反模式（出现任何一条就重做该段）

- 通用的淡入淡出（opacity 0→1 就当出场）；所有东西都从下方淡入上移 20px。
- 画面正中一行字＋发光——PPT／模板感。
- 第五种颜色、渐变彩虹、霓虹发光、扫描线、故障特效——赛博朋克／游戏 HUD 感。
- 网页组件：按钮、导航、卡片阴影、圆角大卡片——「SaaS 网站」感。
- 随机乱飞的粒子或线条，没有结构、没有和排版对话——「随便的 WebGL 示范」。
- 所有段落速度一样；没有一段是真正慢下来的。
