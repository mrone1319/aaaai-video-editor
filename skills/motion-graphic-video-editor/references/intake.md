# Intake 细则（§2）

### 2.2 设计问询（无 Brand Book 时必问）

- **颜色**：主色 + 1–2 强调色 HEX；深底还是浅底——深底配发光系统（模式 A–D 的默认），浅底／暖白配 Swiss 编辑风格（`style-swiss.md`），两套对比策略不能混用；渐变有无方向规定。
- **风格**：极简干净 / Swiss 编辑排版 / 企业稳重 / 奢华金属与 3D 雕塑 / 玻璃拟态 / 生成式计算设计 / 像素复古 / 手作有机。出 2–3 张对比静帧让用户选（`SKILL.md` §4.6）。
- **色调情绪**：冷（蓝青）/ 暖（橙红）/ 高饱和撞色 / 低饱和高级灰。
- **字体**：品牌指定字体文件？无则提议三件套（几何 Display + 中性 Body + Mono 标签）+ 科技感数字字体，出静帧确认。
- **配乐**（质感的天花板）：用户的授权音乐 / **HeyGen 音乐库**（按情绪找 2–3 首试听）/ 套件配乐库 / 原创合成（临时或要求零版权时）/ 静音版；情绪与速度感（紧张 ≈128+、标准 ≈120、稳重 ≈110、抒情 ≈90）；要不要明显 drop。选定后 `music_grid.py fit` 自动挑段落、对拍（`timing.md`）。
- **尾板要素**：logo / 日期 / 城市 / URL / CTA 各要哪些；结尾是 logo 独立淡出、定格到底、还是收黑。
- **禁忌**：不能用的颜色、不能做的效果（Logo 不得旋转/加阴影/变色——很多品牌书明令禁止）。
- **参考片**：有没有想「像」的片子？拿到就先做拆解（`deconstruct.md`），比问 100 个问题都准。

### 2.3 素材清单（向用户要）

| 素材 | 要求 | 没有时的降级方案 |
|---|---|---|
| Logo | PNG/SVG 透明底，深浅两版 | 平底色版可自动抠（`brand-assets.md`）；**完全没有 Logo 就做纯文字排版片并明说——绝不伪造品牌资产** |
| Brand Book / Guideline | PDF，重点读颜色页与字体页（通常在全书 2/3 处） | 走上面的设计问询；或从 Deck/官网截图取色 |
| 产品截图 / 录屏 | 原始分辨率，说明可用区间 | CSS 重绘 UI 或跳过该段 |
| 文案 | 标题/口号/CTA/日期/URL 最终版，**大小写逐字确认**（烧进像素的东西是返工头号来源） | 代拟后必须让用户确认 |
| 参考片 / 喜欢的音乐 | 任意格式 | — |

**录屏素材必须逐段隐私审查**：抽帧看一遍，凡出现真实邮箱、账号、余额、个人信息的区间一律避开，并主动提醒用户该录屏不要原样外流。

### 2.4 有附件时的处理原则

- **能从附件里量出来的，一律实测，不目测**（取色、几何、字宽全部用代码测量）。
- 附件是唯一真相源；用户要求与品牌规则冲突时，**照用户要求做 + 一次性指出冲突**并给一行替代方案，两边都不沉默忽略。
- 用户说"就照你看着办"时，把你选的所有默认值在交付说明里逐条列出，方便逐条否决。

### 2.5 结构确认（动手前最后一步）

问完后**用文字复述整片结构给用户确认**（文字很便宜，帧很贵）：
「开场 X 秒滚数字 → 中段 X 秒产品/信息 → 文案 X 秒 → 尾板 X 秒，色调从 A 漂到 B，唯一的冲击在第 N 小节，对吗？」
