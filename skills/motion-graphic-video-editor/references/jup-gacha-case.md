## 三、开场机制：种子 → 极速拖影 → 减速成形（★可迁移）

逐帧看 0.35–1.25s：

| 时间 | 画面 |
|---|---|
| 0.35–0.48 | 黑场中央一个**极小的青色光点**，别无一物；音频仍是数字静音 |
| 0.55 | 第一道拖影从光点射向画外（音频 0.40 进，第一拍 0.51） |
| 0.62–0.78 | 多道彩色拖影扇形喷出（白/黄/红/蓝），光点长成绿色辉光环 |
| 0.85–1.05 | 环成形，拖影穿环而过 |
| 1.15–1.25 | 环变大，**拖影减速到可辨识 —— 原来它们是卡包** |

**核心：卡片本身就是那些拖影，只是速度不同。减速本身就是揭示。**
不是"先放特效再放内容"，而是同一批物体从不可辨识运动到可辨识——物理动机成立，
所以不像贴上去的效果。

这条比 §7.3 现有的 "Burst 冲击帧"（三层预渲染 + streaks + debris）更省、更真实，
且天然自带景深（前景卡片是纯白模糊涂抹）。

## 五、音画反向：最响的一刻画面停住

- 音频最响 **−9.1dB @7.80s**，正是尾板锁定、画面即将完全静止的时刻。
- 冻结窗口（8.10–9.00s）内音频从 −14.9 衰减到 −44.2dB。
- 黑场呼吸（5.8–7.1s）画面近乎静止（能量 0.60），但**音频保持 −13～−16dB 不挖静**。

> 这条修正 §9.3 现有写法"黑场呼吸处音频同步挖静（dip 到 5%）"——
> 这支片是**视觉挖静、听觉不挖**，反差比同步挖静更有张力。

青起 → 绿爆 → 青沉 → 绿收。**与 Offerbook 的"单向弧线回原点"不同，这支是振荡**：

暗部基调 `#060B11`（Offerbook 是 `#080F15`，几乎同一个值）。

## 七、其他可迁移手法

1. **数字嵌进 3D 空间**：$20,000,000 计数器不是叠在最上层——卡片会从**数字前面**飞过
   （3.0s 可见一张卡糊在数字上）。这一下就把 2D 图层做成了空间里的物体。
2. **数字退场用缩小 + 上移 + 淡出**（5.0s 只剩 "000,000" 半透明上飘），不是切走也不是原地淡出。
3. **计数器落位曲线**：$19… → $19,948 → $19,999,982 → $20,000,000，
   末位先狂转、高位后锁定，锁定点 2.73s 在**正拍**。
4. **绝对静止的尾板**：不是"几乎不动"，是帧差 0.02–0.15 的真静止，持续 0.9s ＝ 全片 9.6%。
   与 Offerbook 尾板仍有微缩放漂移形成对比——**短片用绝对静止，长片用微动**。

## 八、可复用时间轴常量

```js
const FPS = 60, DUR = 9.408, BPM = 161.5;
const BEAT = 60/BPM;        // 0.372
const BAR  = BEAT*4;        // 1.486
const T = {
  silence:    0.00,  // 绝对静音 + 黑 + 一个青色种子点
  audioIn:    0.40,  // 音频进（视觉仍只有种子点）
  firstBeat:  0.51,  // ●第一拍
  streakOut:  0.55,  // 拖影喷出
  ringForm:   0.85,  // 传送门环成形
  blastStart: 1.28,  // ●正拍 卡片风暴开始
  blastPeak:  1.53,  // ◆反拍 ★能量最大（切分，不落正拍）
  numLock:    2.73,  // ●正拍 $20,000,000 锁定
  settle:     3.40,  // ◆反拍 沉降
  numExit:    5.20,  // ◆反拍 数字缩小上移淡出
  breath:     5.80,  // ●正拍 ★黑场呼吸开始（放标语，不是空黑）
  breathEnd:  7.10,  // ◆反拍
  endRise:    7.20,  // ●正拍 尾板升起
  freeze:     7.60,  // ●正拍 ★冻结开始（8.10–9.00 绝对静止）
  fadeOut:    9.10,  // ●正拍
  end:        DUR,
};
```

## 九、与 Offerbook 交叉验证：哪些是"家法"，哪些是单片选择

**两支都成立（＝可直接写进 skill 的规则）**

> ⚠️ **2026-08-12 更正**：下表初版把「零硬切」列为两片共通规律，是错的。
> Offerbook 的 0 切点结论源于检测命令被 `-v error` 静默吞掉输出（详见
> [offerbook 案例第九节](jup-offerbook-case.md)）。重测后 Offerbook 实为 **12 个硬切**。
> **本片 Gacha 的 0 硬切经复核为真**（561 帧全部收到 scene_score，最高仅 0.0719）。
> 三支片实际是 12 / 0 / 2 个硬切——零硬切是 Gacha 的单片特色，不是家法。

| 规律 | Offerbook | Gacha |
|---|---|---|
| ~~零硬切~~ → 硬切数 | ❌ **12 个** | ✅ **0 个**（已复核为真） |
| 正拍/反拍对半分，边界正拍·细节反拍 | 7/8 | 11/11 |
| 单一辉光元素贯穿全片 | blob 变形 | 绿环：传送门→背景光晕→尾板框 |
| 黑场呼吸放内容不放空黑 | Borrow/Lend 切换 | "Catch 'em all" 标语 |
| 黑场呼吸时长 | ~1.2s | ~1.3s |
| 暗部基调近黑冷蓝 | `#080F15` | `#060B11` |
| 绿＋青双色，绿是峰值色 | ✅ `#8FEDA5` | ✅ `#7BCC87` |
| 尾板＝品牌标独立 + 保持 + 淡黑 | ✅ | ✅ |

**两支不同（＝按需求选，不是铁律）**

| 维度 | Offerbook | Gacha |
|---|---|---|
| 时长 / fps / BPM | 25.8s / 30 / 129 | 9.4s / **60** / **162** |
| 峰值位置 | 44%（中段） | **21%（前段）** |
| 峰值形态 | 白场接管（亮度 222） | 3D 卡片风暴（能量 19） |
| 尾板 | 微动漂移 | **绝对静止 0.9s** |
| 色相走向 | 弧线，首尾配比一致 | **振荡**（绿=能量，青=静息） |
| 开场 | 音乐 2.8s 才进 | **0.4s 数字静音** |
