# 品牌资产收割（§4）

> 工具：`$PY "$SK/logo_tools.py" key|bands|split|strip|letters|outline …`（抠图／量版面／切 lockup／去细线／切字形／描轮廓做真 3D）。

### 4.1 Logo 处理（Pillow / numpy）

- **平底色抠图**：按与背景色的明暗差生成 alpha，写出 RGBA PNG。**验证时重读保存后的文件**，不要验证内存数组（numpy 通道索引错误会静默无效：`arr[y:, 3]` 切的是列不是 alpha，正确是 `arr[y:, :, 3]`）。
- **渐变逐像素采样**：沿 Logo 主轴每隔 N px 取实色，得到真实色标序列（若干 hex + 位置）。这条光谱之后驱动：背景光晕色相曲线、渐变文字、分隔条、扫光颜色。
- **尽早切开 lockup**：主标/副标/每个字母分别存 PNG——后期给某个词单做解码／出场时不用重建 3D（真实教训）。
- **真 3D**：`logo_tools.py outline logo.png logo_outline.json` 描出外轮廓与洞，`mg-three.js extrudeLogo` 挤出、正面贴原图（渐变完全保留）；细线（副标、发丝线）先 `strip` 掉，平贴在正面。
- **字形提取共用一条垂直裁切带**（不是各切各的 bbox）：保住真实比例与共同基线，否则 x-height 字母显得过大，一眼假。
- **需要放大的单字母，用 Logo 里切出来的字形，不用字体替代**——它自带品牌渐变和结构。
- **几何用连通域实测**（scipy.ndimage.label）：逐色 bounding box 给出精确元素位置；块状/像素 Logo 要找到构造单元 `u`（最小重复尺寸），动画网格锚定在 `u` 或其整数分之一，重组才像素级精确。

### 4.2 Brand Book PDF 抽取要点（逐页读完）

- 颜色页：**HEX + 渐变 stop 百分比 + 渐变方向规定**（"永远 90° 横向"就绝不能径向用；环境辉光可作豁免但要在交付说明里写明理由）。**限用规则比色板本身更重要**（如"某色只用于价格/奖励，不得装饰用"）——违反限用是片子被品牌方打回的头号原因。
- 字体页：Display/Body/Mono 三件套及字重。
- 图形系统页：品牌自己的形状语言（圆角块/箭羽/几何片）→ 直接当粒子、debris 和转场元素。
- Misuse 页：**逐条当硬约束**（不得旋转/加阴影/改比例/最小尺寸）。

### 4.3 无附件时的取色兜底

用户只给了 Logo 没给色值：从 Logo 取渐变两端色（最左/最右不透明列均色）+ 主色（不透明像素均色），**回报用户确认后**使用。

### 4.4 双品牌合成（赞助/联名单）

- 色相关系判断：色环相邻 → 直接融合；互补/冲突 → 次品牌色只出现在「该品牌专属时刻」（亮相、CTA、尾板）+ 约 1/7 粒子带次品牌色做视觉联姻。
- **主客次序：票/产品/权益属于谁，谁当英雄镜头**；渠道方降为 × 联名行。关系搞反用户一眼打回。
- 不替赞助商编造产品功能——权益文案只写用户给的信息，缺了就问。

### 4.5 产品录屏 / 截图

- 抽帧选界面，存全分辨率 PNG；录屏转 JPEG 序列 ~12fps，裁掉 OS 栏，缩放到显示尺寸 ~2×，总量 <10MB（preload 才快）。
- **数据一致性检查**：片中大字数字/文案与界面截图显示的必须一致。不一致时问用户以哪边为准，然后可做画内修图（`effects.md` 产品演示）。
- 深色 UI 放进深色片几乎无缝；浅色 UI 要加设备机身框。
