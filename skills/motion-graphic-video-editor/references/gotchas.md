# 踩坑速查（症状 → 原因 → 修法，全部付过学费）

调试任何画面问题前先读这里。更快的办法：全量渲染前先抽关键时间点的静帧＋动态预览＋`check_motion`——这些坑多数在一张静帧或能量曲线上一眼可见，在代码里却看不出来。

## 画面

| 症状 | 原因 | 修法 |
|---|---|---|
| 整片发灰、黑不下去 | 闪光写成 `1 - progress`，触发前恒为满亮（多个闪光叠加还会超过 1） | 一律 `MG.imp(t, t0, w)`；打印帧平均亮度，应黑的帧 8–12，>25 有层在漏光 |
| 辉光外有个方框 | 辉光 PNG 边缘不是精确的 0，screen 混合把它放大 | `make_glow.py`（加 padding、硬径向窗、blur 后重套窗）；四角＋边中点必须 `[0,0,0]` |
| 金属 3D 侧面全黑 | 金属只反射环境，场景没有环境 | `studioEnv`；白棚拍铬用暗底＋亮柔光板（`base:'#2E2E32'`），太亮太均匀铬会变灰塑料 |
| 3D 揭示一闪而过 | `expo` 22% 的时间就走完 79% | 揭示用 ~2s `read`／`smooth`；落定 Y 12–16° |
| 宽 Logo 旋转后切边 | 透视把近端放大 ~7% | 竖版 ≤78% 画幅宽；看落定角度那帧验证 |
| CSS 3D 几何对但画面是平的 | `preserve-3d` 子树里有 blend、群组 opacity 或 filter（opacity 0 也算） | 淡入淡出放到非 3D 的祖先或叶元素上；需要真立体就用 mg-three |
| 计数器停错数字 | 落位算法混加 | 用 `MG.counter`（落位＝整圈数×10＋目标数字） |
| 计数器锁定后上下露出邻位 | 视窗和格高一样高 | `MG.counter` 已用 1.25em 格高＋1.15em 视窗 |
| 滚动中数字清楚得像乱码 | 模糊按「进度」不按「速度」驱动 | 模糊跟真实速度走（`MG.counter` 已做） |
| 科技字体字挤在一起 | 按单字宽累加 | 按前缀宽度定位＋补字距 |
| 换画幅后偏离中心 | 手算 `top`、残留 `translateX` | 居中堆叠 `.stack`＋`width:max-content`，或 `MG.grid` |
| 字距文字整行偏左 | 最后一个字的字距 | `text-indent` ＝ `letter-spacing` |
| 版面全挤在一起、字消失 | 在隐藏图层里量字宽，量到 0 | 用 mg-film（setup 时图层参与排版但不可见）；自己写的就先 `visibility:hidden` 再量 |
| 颗粒像镜头脏了 | 静态噪点 | 每帧按 `Math.floor(frame)` 移动纹理（运动模糊子帧之间不动） |
| 光谱环有接缝 | conic 首尾相撞 | 光谱铺 ~86% 圆周＋回程弧压暗 |
| 竖版上下死黑 | 正圆光晕按宽度定尺寸 | 纵向拉椭圆 `scaleY≈(H/W)*0.92` |
| 文字被淡出的产品盖住 | 叠层顺序错 | 文案／尾板放独立的顶层容器 |
| 粒子少了一半 | 出生范围 ≠ 回收距离 | 同一个常量用在两处（`GEN.particles` 已用环绕） |
| 多重色波读作闪烁 | 波间隔 <0.4s | 整拍间隔（2 拍有仪式感） |
| 变身飞行时字形撕碎／块间发丝缝／飞入的格子像碎片 | 全局排名映射／格子正好等于 pitch／没穿新颜色 | 包围盒内归一化位置配对／格子 ×1.12／新元素全程穿新色 |
| 扫描线把黑场雾化 | normal 混合 | multiply |
| numpy 改 alpha 没效果 | `arr[y:, 3]` 切的是第 3 列 | `arr[y:, :, 3]`；**重读保存的文件**验证，不要验证内存数组 |
| 「动作很平、后半段没力」 | 死时间太多（旧片实测 52% 的帧几乎不动） | `check_motion` 看能量曲线；加镜头呼吸、视差、错峰；缓动换有重量的 |
| 能量验收误报字太小／超出安全区 | Swiss 小标签、刻意出血的大字 | `data-deco`／`data-bleed` |
| 能量验收误报跳变 | 设计好的硬切、按拍跳格 | `MG.cut(t)`；有意的停留 `MG.hold(a, b)` |
| 时间窗口算反、元素一开始就在终点 | 事件排到了自己的结束之后（例：推进开始晚于本场结束） | `MG.prog` 现在会报错；检查 `T` 的先后 |

## 渲染与音频

| 症状 | 原因 | 修法 |
|---|---|---|
| 全部帧一模一样／场景永远不 ready | 构建期 JS 异常（最常见：const 声明前就引用） | 渲染器挂了 `pageerror` 会报错；按报错修 |
| 偶发「scene never became ready」 | 多个浏览器同时向本机服务器要文件，等待队列太小 | 渲染器已把队列加大并自动重载；自己写服务器也要注意 |
| file:// 下 ES 模块、Lottie、`getImageData` 失败 | 浏览器的本地文件安全限制 | 渲染器、播放器都用本机临时网页服务器载入场景；`--root` 要包住所有引用的文件 |
| 成片比预期短（例：55 秒只剩 45 秒）却「渲染成功」 | 配乐比影片短，`-shortest` 静默截掉影片 | 渲染器与 `encode.sh` 现在都补静音、按画面长度切；会警告「配乐太短」 |
| 重新剪的配乐没生效、或命令卡住不动 | ffmpeg 输出没加 `-y`：档案已存在时停下来问要不要覆盖 | 所有 ffmpeg 呼叫都要 `-nostdin -y`（脚本已修） |
| 配乐总是短 ~90 毫秒 | 响度滤镜吞掉结尾，且之后的补静音无效 | `music_grid.py` 两步做（先响度、再补足长度）并核对长度 |
| 改了片长，画面还在音乐已停 | 没重新生成配乐 | 真实配乐 `music_grid.py fit --dur` 重跑；合成配乐两个文件同改 |
| 运动模糊看得到一层层「分身」 | 子帧太少，快速移动时间隔太大 | `--mblur` 已自适应加密到 64 子帧 |
| 运动模糊把硬切糊成交叉溶解 | 快门窗口跨过了切点 | 渲染器用前向快门（`[f, f+快门)`），切点落在帧边界就不会跨；别把切点放在小数帧 |
| GPU 与 CPU 渲染的帧接在一起有细微跳动 | 两种光栅的抗锯齿差 <1 像素 | 一支片从头到尾用同一种（局部补渲也一样） |
| 透明图层边缘有锯齿 | GPU 截图的透明边缘只有 19 级渐变 | `--alpha` 自动走软件渲染（75 级） |
| 检测说「零硬切」 | `metadata=print` 配 `-v error` 什么都没印 | `analyze_reference.py` 会核对收到的帧数；结果为 0 先证明管道读到了数据 |
| 声音「刺耳／有噪音」 | 通常是方波 pad、音区太低、压太满，不是高频太尖 | 先量频谱再动手（`score.md` 末节） |
