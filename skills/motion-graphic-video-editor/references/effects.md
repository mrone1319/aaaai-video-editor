# 效果配方库（§7）

> **进来之前先锁定构思（`concept.md`）。** 这里是**取材库，不是菜单**——每取一个配方先答「它如何服务于那一个构思」，答不出就不用，即使很好看。从目录挑零件拼装，正是成片「有配方没构思」的直接成因。
> 已经做进工具库的手法只写「用哪个函数＋关键参数」；没进库的写规格。

## 1. 文字

- **渐变扫光**（「高级感」）：`MG.reveal(parts, t, t0, {style:'sweep', tint:品牌色, color:纸白})`——四通道一起动（透明度、颜色、上移、模糊），柔边 30% 行宽。金句用「品牌色落白」，URL／数字用「保持品牌色」。只做透明度显得廉价，四通道成本一样。
- **整块渐变扫光**（数字锁定后的奖励，全片一次）：品牌色→白的线性渐变左→右扫过整块字 ~0.4s；是文字的渐变**填充**（`background-clip:text`），所有字共用同一条渐变（同一 `backgroundSize`、各字 `backgroundPosition` 取负偏移），否则是六道扫光不是一道。
- **遮罩滑出**：`style:'mask'`，逐字 0.03–0.04s 错峰——最有设计感的标题出场。
- **逐词追加＋整行重新居中**：「Now」→「Now liquid」，新词有自己的落位微动、旧词同时提亮（Offerbook 签名手法）。
- **逐词点亮**：已读词亮、未读词暗——「正在被说出」的节奏，权益行专用。
- **顺序列表**：每半小节落一行（icon＋序号＋词），落位时 icon 一次小脉冲；N 项就按序用满品牌光谱的 N 色。
- **解码揭示**：`MG.decode`；乱码池用**品牌 Logo 切出的字形**，中间帧也全程是品牌的；配 ~30Hz 细碎 click＋每锁一字一声递升 chime。当**开场钩子**用最有效（Showcase）。和 3D lockup 接力：主标先落定 → 旁边的字以平面字形解码 → ~0.16s 闪一下换成挤出版（同一张图同一位置，只是多了深度，读作「它变成真的了」）。
- **品牌字形卡**：整屏单字母（`logo_tools.py letters` 共用垂直带裁切，保住真实比例与基线），每张 1s 硬切；0.5s 读不到配词。
- 卡片里出现品牌名时**用 Logo 图，不用字体排**——用户第一轮必提。

## 2. 数字

- **老虎机／里程表**：`MG.counter`。各位转不同圈数、高位先锁、锁定回弹、模糊与遮罩羽化跟转速——这些都是「像真机械」的必要条件，库里已做。锁定的那一刻对拍，配一次 `MG.imp` 小放大。
- **锁定变色**：两层相同的数字（品牌渐变层／纸白层）在锁定时 0.3s 交叉——「带着品牌色到达、落定成白」是很强的一拍。
- **数字嵌进空间**：让前景物件从数字**前面**飞过一次，2D 图层就变成空间里的物体（Gacha）。退场＝缩小＋上移＋淡出。
- **数字字体是气质的一半**：出 6 款对比静帧让用户选（几何／techno 读作数码；七段管读作时钟且 `1` 是光杆）。Orbitron 这类侧边留白≈0 的字：按前缀宽度定位、字距补 ~0.085em；斜杠零不是 bug。

## 3. Logo 与 3D

- **真 3D Logo**：`outline` ＋ `extrudeLogo` ＋ `studioEnv`（`authoring.md` §5）。揭示用 ~2s 慢缓动（`read`／`smooth`），**不要** `expo`——它 22% 的时间就走完 79%，揭示还没看清就结束；落定停在 Y 12–16°（停在 ~5° 深度感就没了）；宽 Logo 旋转时近端会被透视放大 ~7%，竖版控制在 78% 画幅宽以内，验证要看**落定角度**那帧。
- **修饰**：两盏品牌端色的轮廓光把 Logo 从背景托出来；地板倒影通常不值得（像污渍）。
- **冲击帧（burst）**：三层预渲染辉光——光谱环（`make_glow.py`，0.10→1.00 `expo` 0.34s 再缓漂）＋热核心（0.34→2.1 放大、0.55s 内消失）＋~16 条渐变射线（screen、种子化随机延迟）＋品牌形状碎片 ＋ 一次 `MG.imp` 径向闪光 ＋ **同帧一声音频撞击**。
- **减速即揭示**：开场的高速拖影就是内容本身，减速到可辨识的那一刻就是揭示（Gacha）——比「先放特效再放内容」更真、更省。
- **信号脉冲**：对 Logo 某个元素做短暂亮度／缩放脉冲，与色波同拍。

## 4. 变身／重组（模式 C 核心）

- **像素网格采样**：源图与目标 Logo 采到**同一张**方格网（锚定 Logo 的构造单元 u），存 JSON 载入；运行时不读像素。
- **匹配**：按「各元素包围盒内的归一化位置」配对（KD-tree），**不按全局排名**——排名映射会把字形飞行中撕碎；按位置配对让 C 落回 C，飞行途中仍可读。
- **新格子**（无来源）：从画外 360° 射入（半径 2.5–4× 画布）带切向卷曲，**全程穿新形象的颜色**；**旧格子无人认领**＝碎片，外爆淡出于揭示之前。
- **飞行**：位置 `inOut` ＋ 钟形弧线／升力／旋转 ＋ 落地 `MG.imp` 小弹；颜色在各自飞行中点后旧→新交叉。格子画成 pitch ×1.12（正好等于 pitch 会出发丝缝）。
- **块碎裂**：碎前一次脉冲抖动预震，再按 x 位置错峰飞（像波浪回流，不像散场）。
- **生长／殖民**：按离种子距离出生 `t0 + span*pow(d/dmax, 0.85)`，弹性放大，出生时亮、落定回本色。
- **冲击波网格**：全屏小方格场，高斯亮带 `exp(-((d-r)/w)²)`，带宽取半对角线 14–20%（太窄像描边）；多波＝每个品牌色一波，**整拍间隔**（<0.4s 读作闪烁）；Logo 周围留椭圆豁免区。末波后留 5–9% 透明度的残留微光（「殖民地留下了」）。完整构思级范例见 `formulas.md` 第五节。

## 5. 转场

| 手法 | 做法 | 适用 |
|---|---|---|
| 硬切 | 直接换；需要喘息时收黑层 ~3 帧尖峰；跨切钉住一个元素（match hold） | A／C／D／H |
| 黑白反转 | `MG.invert`＋`MG.swap` 同帧换墨与纸 | H、编辑风格 |
| 裁切擦除 | `MG.clip`（方向／圆形／斜切／百叶／错峰直条） | H、D |
| 推进穿越 | `MG.zoomTo` 推进某个字或格子，在里面切到下一场（例：推进字母 O 的内孔落在下一场的底色上） | H、A |
| 版面变形 | `MG.rect` 把一个面板扩成全屏，接下一场 | H |
| 甩镜 | `MG.ease.whip` 横移 ＋ `MG.blur` 宣告运动模糊 | A、D、H |
| 重叠溶解 | 退场放大 ~112%＋模糊 0→18px＋淡出；进场位移步长递减；重叠 0.35s | B |
| 白场 | 1 秒纯白＋黑字，**硬切进、硬切出**，夹在暗调片中段当最大亮点（Offerbook） | B、A |
| 形状擦除 | 40+ 大圆角块分 5–7 行错峰横掠（lag 0–0.16s），中心被完全盖住那一刻换底 | D |

## 6. 产品演示／真实录屏

- **设备框**：CSS 画机身，屏内 `<canvas>` 逐帧画录屏序列——**绝不用 `<video>`**（不确定性）。
- **Playlist 映射**：`[片头时间, 片尾时间, 素材起点, 速率, zoom?, pan?]` 表把影片时间对应到素材时间——每个功能词落位的瞬间正好出现对应界面。
- **相机三层**：相机层（推拉平移）→ 入场层（升起／退场）→ 机身层，各管一件事，**每层显式宽高**（塌成 0×0 会带偏缩放原点）。最重要的卡真的推进去：占画幅宽 90%+、停足 1.5s；推进倍率按画幅反推，不写死。
- **点击反馈**：白色圆环涟漪 0.3s，不画手指不画光标。底部弹层：面板上滑时底层同步缩到 94%、压暗 55%（底层不动就穿帮）。
- **画内修图**（素材数字与文案冲突时）：盖掉旧字、同字体同字高同渐变 8× 超采样重画。**做了必须告知用户**。

## 7. 背景／氛围

- **预渲染辉光 PNG**（`make_glow.py`）：画在加 padding 的画布里、硬径向窗让外圈精确归零、blur 后重套窗，四角＋边中点必须 `[0,0,0]`——「看起来黑」常常还有 15–120/255，screen 混合下会露出方框（真实翻车：「圆形效果有个方形的外框」）。
- **光谱环接缝**：conic 渐变首尾相撞会经过脏色——光谱只铺 ~86% 圆周，回程弧压暗当背光面。
- **景深**：DOM 场景用 `MG.camera` 多层视差＋`dof`；大量粒子用 `GEN.particles`（2D）或 `mg-three` 的 `particles`（3D）。
- **CRT／8-bit 套件**（只在用户要「像素复古」时）：3px 扫描线缓滚（multiply）、撞击帧 ±5px 单帧水平踢动（一上一下两个 `imp`）、像素点阵背景慢漂。
- **廉价质感件**：四角定位括号、光谱分隔条（品牌色序圆角条 `scaleX` 0.2→1）、点阵底纹（~46px 平铺 1.7px 点 16% 透明度慢漂）、Swiss 的细线与十字定位标（`style-swiss.md`）。

## 8. 收尾

- **坍缩留黑**（模式 B 唯一的冲击）：收尾前光晕先冲到最亮（`imp` +55%）再 0.4s 内坍缩近黑。没这口「吸气」，尾板没有决断感。
- **分步信息卡**（「结尾太挤」的标准解法）：一次一条，同一位置轮播，**每张 2–3s（2s 是地板）**；等宽小标签＋大值；退场上移淡出；mini lockup 钉在上方品牌不断线。用户嫌挤就**拉长影片**，绝不压缩卡片。
- **尾板**：Logo 6% 过冲弹出后整组缓缩；信息分层错峰进场（Logo→分隔条→日期→URL，间隔 0.15–0.4s）；一屏最多三行。
- **Logo 独立签名收尾**：尾板经黑退出 → 主标独自出现在纯黑上 → 停 ~2.5s → 淡黑；配乐在其下衰减（`score.md`）。短片尾板可以绝对静止；长片先微动 ~5s 再定格最后 1–2s（`formulas.md`）。
- 结尾必须有一个**封面级的停留帧**（≥1.5–2s 稳定、核心元素在安全区、缩图可读），用 `MG.hold` 宣告。
