# MR ONE 频道剪辑规则（从 ep01–ep11 的实战教训提炼）

> © 2026 MR ONE（@mrone.ai）。本档案是 MR ONE 频道的剪辑规则，随 aaaai-editor 套件提供仅供参考；
> 配套的 `mrone` 风格与字幕样式仅限 MR ONE 社群成员或获 MR ONE 授权者使用（`aaaai-editor authorize mrone`）。
> 想建自己的频道档案：复制 `profiles/TEMPLATE/` 到 `~/.aaaai-editor/profiles/<你的名字>/`，再 `aaaai-editor config --set profile=<你的名字>`。

> 个人机器上的私有补充（策划档案位置、归档位置等）放在 `~/.aaaai-editor/profiles/mrone/rules.md`，会在这份之后读、并优先。

这里只列会影响 aaaai-editor 剪辑决策的规则；工具已经自动做到的，标 ⚙️。

## 开工前

- **有策划档案就先读**（位置写在你自己的 `~/.aaaai-editor/profiles/mrone/rules.md`；没有就跳过）。
  里面的硬规定照做（例：价格／截止日不放进视频和字幕，因为视频会一直在线）。
- **每集背景要不一样**：对照前几集画面，重复就回报，不要自己裁切掩饰。
- **原片是唯一不可再生的资产**：永远不删、不移动、不覆盖素材；清理只清可重算的中间产物。

## 转录后：字数闸门 ⚙️（transcribe 会印出来）

`字数 ÷ 203 字/分 = 预估秒数`（实测语速）。≤75 秒正常；76–85 秒回报用户但可继续；
**>85 秒停下等改稿**——不要排字幕、做卡片，免得白工（用户：「口水要砍掉，内容一个都不要砍」）。
人声比底噪低于 15dB ⚙️ 要提醒：环境噪声后制救不回来，下次麦克风靠近、避开风扇／冷气出风口。

## 剪点 ⚙️（autocut 默认按能量包络修）

- 段尾切在**尾音衰减回底噪之后 +0.06s**，不是静音检测判定的那一刻（ep07：每段最后一个字都被咬）。
- 段头放在**起音前 0.09s**，而且那一刻要是安静的（ep08：贴太近咬掉字头，「那」变「然后」）。
- 砍掉一句话之后，下一段起点要在那句话**结束后的静音里**，不是下一句的起音点（ep08：冒出没头没尾的「管理」）。
- 连续说话中间要切：找 >250ms、谷底很低的换气凹陷，<150ms 的多半只是辅音。
- 验收：`check-sync` 的剪点审计；拿不准的接点用 `aaaai-editor listen` / `aaaai-editor probe-cut` 实听。
  **判定性听写一律不带提示词**（提示词会在静音上幻听出词，ep10）；「窗口里听到」≠「在窗口开头」，要逐步收窄。

## 字幕

- **中文每句必须单行** ⚙️（超宽会警告）。太长就在**标点后**拆成两句独立字幕，绝不切在词中间；
  纯中文约 18–20 字是上限，混英文专有名词会更早超。
- 拆出来的句尾若只剩悬空逗号／破折号要清掉 ⚙️。
- **英文单词首字母大写**，尤其名词：Brainstorming、Token、Skills、Website、App、Backend、Frontend。
- **同一句里并列的名词，高亮要一致**（「交给 Cowork 或者交给 Code」两个都上色）。
- 常听错：「造工具／造轮子」不是「找工具／找轮子」；Developer 不是 Dualipper；Mr.Wen 是 **MR ONE**
  （词表 `glossary.json` 会自动修 ⚙️）。**人名／专有名词联想不出来时，先用 `aaaai-editor listen` 剪出那段给用户确认**，不要照听写定案。
- 结尾附近突然冒出一句风格不像他的话（「请不吝点赞订阅…」）多半是 whisper 在静音上幻听 ⚙️（transcribe 会丢掉并列出来）。
- **对时流程**：改完字幕轨 → `aaaai-editor align`（逐句贴到真实人声）→ `aaaai-editor check-sync` →
  `aaaai-editor preview --subs` 出一分钟字幕预览**给用户确认** → 用户点头才做完整渲染（ep05 为了看对时重渲 5 次＝75 分钟）。

## 配乐

- 流程：看逐字稿语气＋抽几帧看场景 → 定调性 → 先查 HeyGen 曲库（`media-use` skill，已认证）→
  没合适的用常备配乐库（`aaaai-editor bgm`，7 首原创、零版权）→ 都不合适才用 `tools/gen-bgm.py` 现烧。
- `db` 从 **-18** 起（-24 在语句空白处几乎听不见）。**定案前出 A/B**：`aaaai-editor music-ab` 出三种音量给用户听，不要猜。
- HeyGen 曲库的曲子留意授权范围，不确定就提醒用户。

## 构图

- 机位坐得远：问用户要不要全局推近，用 `aaaai-editor framing` 出 3–4 档倍率对比图让他**看图选**，不要用文字描述；
  选定写进 storyboard 的 `framing`（并进第一次编码，不多压一代）⚙️。
- 推近上限：物件变明显、脸维持中景；约 **1.15–1.25×** 安全，1.46× 用户觉得「脸太清楚」。

## 素材

- 黑色／透明底的 logo（GitHub、ChatGPT 这类）不能直接放深色卡：`image` 卡片加 `"disc": true` 垫白底圆片 ⚙️。
- 旁白＋现场画面格式（非桌前口播）：台上／展示／作品画面**必须逐帧确认是他本人**才能配他的旁白；
  会误导的元素（别人的奖金横幅等）逐支查；近距离拍到别人的脸先不用，等用户决定。
  场景型片子要加长时加画面停留，不加话。

## 响度 ⚙️

成品 **-14 LUFS（±0.1）、真峰值 ≤ -1 dBTP**，每集一致（用户听得出各集音量不统一）。render 会印出实测值，核对一下。

## 交付

- **只出一个版本**：`out/final.mp4`（母带），不出 -web 上传版，除非用户要求。
- 母带常超过手机 30MB 传输上限：要在手机上看就 `aaaai-editor phone` 另压一支预览（不是交付物）。
- **封面是固定交付物**：`aaaai-editor cover`——成片挑一帧、6–8 个招牌金 #F4C430 大字（该集钩子的最短浓缩）、
  关键文字在四周各留 15% 的安全区、署名用设置里的 `handle`、**绝不挡脸**；出 1080×1920 与 1080×1350，
  用 Read 看 `cover_check.png`（Reels 全画面 vs 主页裁切）再交。封面字放**事件**、不放结论（金句留在片子里当截图点）。
- 卡片验收要抽**成品**的帧（每张看中段与收尾前 0.2s），不要只看预览或静态图。
- 归档：`<history_dir>/<频道名>/`（`aaaai-editor config` 看 history_dir），视频来源写母带路径，
  记下成片／封面路径、内容重点、待决问题。

## 发布之后

用户说「第 X 集发布了」：确认 `out/final.mp4` 与 storyboard 都在之后，自动清掉可重算的中间产物
（`work/` 里的 mp4／wav／mkv、`work/segs/`、`work/mattes/`、`work/plates/`），**保留** `work/*.json`（字幕轨、转录）；
素材不在的项目不要自动清。清完回报释放了多少空间。
